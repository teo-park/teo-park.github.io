# 어부 스킬 안내

운영자가 작성한 어부 스킬 정리 자료를 바탕으로 만든 낚싯대 낚시 안내입니다. 원본 프레젠테이션은 배포하지 않습니다.

[터주 유형별 공략](./big-fish/)은 직접 낚시·생미끼·직감 준비의 7가지 기본 유형과 4가지 추가 조건, 대표 어종을 설명합니다. 홈과 상단 메뉴의 **어부 가이드** 그룹에서 스킬 안내와 같은 단계로 이동합니다. 기존 주소와 본문 앵커는 유지합니다. 개별 어종에 공략을 자동 배정하지 않습니다. 내용 수정은 `big-fish/content.cjs`, HTML 생성은 `node ffxiv/fisher-skills/big-fish/build.cjs`로 합니다. 대표 이름은 수첩 데이터에서 읽으며 원문 공략과 기술 안내에 연결합니다.

두 가이드는 `guide-layout.cjs`의 제목·탭·목차와 `guide.css`의 본문 폭·카드·반응형 배치를 공유합니다. 스킬 안내 목차는 검색·분류로 가려진 설명을 펼쳐 이동합니다. 그룹 이름과 두 페이지의 제목은 `../tools/site-navigation.cjs`에서 관리합니다.

공략 본문의 스킬명에는 16px 공식 아이콘과 설명 미리보기가 붙습니다. 마우스 오버·키보드 포커스·모바일 탭을 지원하며, 설명 안에서 해금 레벨·GP·효과·주의점과 상세/공식 링크를 확인합니다. `skill-tips.cjs`는 이 페이지의 검토된 설명과 `official.json`을 재사용하고, JavaScript가 없을 때도 기술 안내 링크는 동작합니다.

- 숙련 낚시꾼: 이미 활성화된 생미끼 프록을 지우지 않고 켤 수 있다는 점과 쿠얼 → 쿠얼 → 홍룡 실전 흐름을 먼저 설명합니다. 활성화 전 어획에는 소급 적용되지 않습니다.
- 인내의 월척 확률 증가와 대물 낚시의 월척 보장을 구분합니다.
- 이중·삼중 수량, 루어 크기 유인, 입질 시간 사례를 확정 어종·확정 성공으로 오해하지 않도록 설명합니다.
- 루어 항목에는 재추첨(리롤), 평소 입질 구간이 지난 어류의 재등장, 마지막 사용 후 약 5초의 입질 억제를 설명합니다. 캐스팅 10초에 사용한 가상 예시 표로 짧은 입질이 겹치는 현상과 긴 입질의 기존 시간 유지를 구분합니다. 출현 시간·날씨·직감·환해류 종료 뒤에는 마지막 캐스팅의 기회를 잃을 수 있음을 안내합니다. Fruity Snacks의 공개 연구 정리, 직감 종료 실험, 한국 서버 공략을 항목 안에 연결하며 공식 효과와 커뮤니티 관측을 구분합니다. 터주 유형별 공략의 스킬 미리보기에도 요약과 주의점을 반영합니다.
- 소장품 확인 창·모션 입력은 공식 보장 효과와 구별한 운영자 실전 팁입니다.
- 검색(초성·한글 조합 중 입력 포함), 목적별 필터, 스킬별 주소와 관련 기술 바로가기를 지원합니다. 필터로 숨겨진 기술의 링크를 열면 필터를 해제합니다.
- 전체 목록은 월척·생미끼 / 기본·입질 조절 / 어종 저격 / 직감·다수 낚시 / GP·보조의 다섯 구역으로 나눕니다. 검색 결과가 없는 구역은 숨깁니다.
- 각 스킬의 아이콘·이름 옆에 공식 해금 레벨을 개별 표시합니다. 공식 가이드가 별도 퀘스트를 표시한 기술은 해당 해금 퀘스트에도 연결합니다. `official.json`의 `level`과 `quest`가 기준입니다.

## 수정·검증

`content.cjs`는 편집한 설명, `official.json`은 공식 이름·아이콘·링크 앵커입니다. `node ffxiv/fisher-skills/build.cjs`로 검색 엔진과 JavaScript 미지원 브라우저에서도 읽을 수 있는 HTML을 생성합니다. `node --test ffxiv/fisher-skills/tests/*.test.cjs`로 검색과 기술 간 이동을 확인합니다.

기술 이름·레벨·GP·효과·아이콘 출처: [한국 공식 어부 가이드](https://guide.ff14.co.kr/job/Fisher/31?type=L). 해당 페이지는 패치 7.0 기준으로 안내하며, 2026-09-10 확인했습니다. 패치별 최신 수치는 게임 내 툴팁을 우선합니다. 쿠얼·홍룡 조건은 [Teamcraft 홍룡 자료](https://ffxivteamcraft.com/db/ko/item/24993)에도 연결합니다.
