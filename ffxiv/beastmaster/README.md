# 마수도감

패치 **7.56** 마수도감 **50종**의 수집 기록과 획득처를 확인하는 정적 웹 도구입니다. 공식 한국어 명칭 ‘마수도감’을 사용합니다.

- [마수도감 열기](https://teo-park.github.io/ffxiv/beastmaster/)
- **5열 × 5행, 25종씩 2페이지**. 사용자가 제공한 공식 도감 이미지의 1~25번 배치에 맞췄습니다. 검색·필터 사용 시 결과만 모아 표시하며 각 마수의 번호는 유지합니다.
- 칸을 눌러 수집 체크, 획득처 버튼으로 포획 장소와 항아리 가격·선행 퀘스트 확인. 상세창 상단 닫기는 본문 스크롤과 별개로 고정됩니다.
- 번호·한글·초성·영문·획득처 검색, 미수집/수집 완료 필터, 필드/임무/항아리/퀘스트별 필터, 장소별 묶음 보기.
- 획득처에 몬스터 위치 지도: 마수 35종에 인벤 토벌수첩의 대표 위치 40개를 연결했습니다. 실제 몬스터 이름·초성으로도 검색할 수 있고, 대상이 여러 개면 지도에서 선택할 수 있습니다. 좌표 복사와 각 위치의 인벤 원문 링크를 제공합니다.
- 미수집 보기에서 체크한 칸은 ‘체크 반영해 목록 정리’를 누를 때까지 남습니다. 필터나 보기를 바꾸면 새 수집 상태로 갱신합니다.
- 수집 기록 관리: 번호 범위로 일괄 등록, 현재 페이지 일괄 체크, JSON 파일 내보내기·가져오기와 붙여넣기, 마지막 변경 실행 취소.

## 수집 기록

브라우저 `localStorage`의 `teo-ffxiv.beastmaster.collection.v1`에 번호로 저장합니다. 계정 로그인·서버 전송·자동 동기화는 없으며, 다른 기기로 옮길 때 백업 파일을 사용합니다. 브라우저 데이터 삭제 전에 내보내기 하세요. 다른 수첩의 기록은 건드리지 않습니다.

백업 형식: `{ "type": "ffxiv-beastmaster", "schemaVersion": 1, "exportedAt": "…", "collected": [1, 4, 6] }`. 가져오기는 **기존 수집 기록에 추가**하며 누락된 번호를 해제하지 않습니다. 현재 목록에 없는 양의 정수 ID도 다음 버전을 위해 보존하고, 현재 50종의 수집률에는 포함하지 않습니다. 저장 전에 다른 탭의 최신 상태와 합치고 실행 취소 시 관련 없는 변경을 보존합니다.

번호 등록에는 이 페이지의 No. 번호를 사용하세요. 게임 캡처 자동 인식은 아직 포함하지 않았습니다.

| 주요 출현 지역 | 필드 37종, 임무 12종 |
| 첫 마수 쿠시 | 잡 개방 퀘스트 진행 중 항아리 지급 확인 |
| 코르나고 항아리 | 16종, 사용 시 해제되는 마수 ID 연결 |
| 항아리 상점 교환 | 15종의 비용·화폐·선행 퀘스트 연결 |

| 정확한 포획 좌표·대상 개체·난이도·확률 | 아직 연결하지 않음 |
| 기존 몬스터 출현 참고 지도 | 35종 · 대표 위치 40개. 포획 확인 좌표와는 별개 |

`XBMPet`의 빈 0번 행은 제외합니다. 일반 소환수나 꼬마친구를 마수도감에 섞지 않고 `XBMPet → Pet` 참조로 범위를 정했습니다. 쿠시의 서식지 설명을 포획 장소로 사용하지 않습니다. 쿠시는 `마수를 조련하는 사람들` 퀘스트 중 받은 아이템 49805를 사용하며, 이 사실은 퀘스트 대사 파일의 지급 안내에서 확인했습니다. 퀘스트 완료 보상 목록과는 구분합니다.

장소는 **게임 도감의 ‘주요 출현 지역’ 힌트**입니다. 예를 들어 청설모는 검은장막 숲 중부삼림, 슬라임은 구리종 광산으로 연결됩니다. 같은 장소 번호라도 필드의 `PlaceName`과 임무의 `ContentFinderCondition`을 구분합니다. 같은 종에 속하는 여러 마물, 실제 포획 가능한 개체, 세부 좌표는 별도 대조가 필요합니다. 게임의 ‘파악하기’로 가능 여부와 난이도를 확인할 수 있습니다. [한국 공식 패치노트](https://www.ff14.co.kr/news/notice/view/2947)

상점 교환은 `Item → ItemAction → XBMPet` 및 `SpecialShop`의 실제 참조와 가격으로 연결합니다. 쿠시 1종은 퀘스트 지급, 나머지 항아리 15종은 저순도/고순도 마수핵 교환을 확인했습니다. 상인의 위치(중부삼림 X:21.9 Y:22.6)는 공식 패치노트에서 확인한 좌표이며 **마수 포획 좌표가 아닙니다**.

## 데이터 구조

`data.json`에는 다음 키가 있습니다.

- `beasts`: 마수 50종. `id`는 XBMPet ID, `petId`는 Pet ID입니다. 향후 수집 체크의 저장 키는 이름 대신 `id`를 사용하세요.
- `locationHint`: 필드/임무 종류, 원본 테이블과 ID, 한국어 장소명. 쿠시는 `null`입니다.
- `acquisition`: 포획 장소 힌트 또는 항아리 아이템 참조. 항아리의 자세한 비용과 선행 퀘스트는 `items[].sources`에 있습니다.
- `actions`: 기술 ID를 키로 한 사전. 마수별 `actions` 배열은 Pet의 원본 슬롯 번호를 유지합니다. 슬롯 의미를 임의로 분류하지 않았습니다.
- `coverage`: 연결된 항목 수와 후속 확인 대상 ID입니다.
- `unmapped`: 의미가 아직 확인되지 않은 원본 열 값입니다. 이를 포획 레벨·난이도·스탯으로 해석하지 않았습니다.

`tooltip.raw`는 게임 원문, `tooltip.text`는 서식 태그를 제거한 **미리보기**입니다. `hasConditions: true`이면 캐릭터 레벨 등 조건에 따른 표시 분기가 남아 있습니다. 해당 기술의 효과를 항상 발동하는 것으로 간주하거나 아직 딜 계산·조합 추천에 바로 사용하면 안 됩니다.

도감 번호는 원본 ID를 보존합니다. 제공된 공식 이미지에서 5×5 배치와 1페이지의 1~25번, No.1 쿠시, No.4 푸길, No.6 도도 등의 대응을 확인했습니다. 2페이지 전체 아이콘은 아직 개별 대조하지 않았습니다. 초기 수집 상태를 추정하거나 사용자의 게임 기록을 읽지는 않습니다.

아이콘은 게임 리소스 경로와 XIVAPI URL만 기록했습니다. **2026-09-08 확인한 마수 아이콘 3종(1·25·50번)의 URL은 404를 반환했습니다.** 50종의 아이콘 ID는 확보했지만 실제 이미지가 모두 준비됐다는 뜻은 아닙니다. 표본 결과와 확인 시각은 [asset-status.json](./asset-status.json)에 기록했습니다. 신규 패치 아이콘이 이미지 서버에 반영되는 시점은 별개이며 원본 이미지 파일을 복제하지 않습니다.

## 원본과 재현

### 몬스터 참고 지도

[인벤 토벌수첩](https://ff14.inven.co.kr/dataninfo/hunting/list.php?dataidx=51)의 몬스터 이름·추천 지역·좌표를 [locations.json](./locations.json)에 별도로 저장합니다. [location-links.json](./location-links.json)은 마수 종과 실제 몬스터 이름을 대조한 명시적 연결표입니다. `커얼`이라는 글자가 들어간 `커얼발톱 난봉꾼` 같은 인간형 적을 자동으로 포함하지 않으며, 공용 토벌수첩 아이콘만으로 분류하지 않습니다. 선택된 이름은 한국어 `BNpcName`과 정확히 일치하는지 확인하고 ID를 보존합니다.

**이 지도는 기존 몬스터의 출현 참고 위치이며, 패치 7.56에서 해당 좌표·개체의 포획이 검증됐다는 뜻이 아닙니다.** 인벤 자료의 갱신 시점은 확인되지 않았으며, 게임 패치로 배치가 달라졌을 수 있습니다. 모든 항목은 `captureVerified: false`입니다. 같은 몬스터·소지역이 여러 클래스 토벌수첩에 반복되면 첫 번째 유효 좌표를 대표 위치로 사용하고 원문 링크를 보존합니다. 여러 좌표의 평균이나 임의 좌표를 만들지 않습니다. 숫자만 표시된 토벌수첩 순번을 몬스터 레벨로 쓰지 않습니다.

푸크·금강거북·왕두꺼비 3종은 도감 주요 출현 지역과 다른 지역의 참고 위치이며 지도에 그 차이를 표시합니다. 임무, 신규 몬스터 등 인벤에서 대응을 확인하지 못한 항목에는 임의 지도를 만들지 않습니다. 기존 필드/임무/항아리 획득 경로와 수집 기록은 그대로 유지합니다.

지도 배경은 XIVAPI의 게임 지도 이미지 URL을 사용합니다. 인벤의 지도 스크린샷이나 페이지 레이아웃은 복제하지 않습니다. `Map`의 지역 ID·축척으로 게임 좌표를 이미지 위에 표시하며, 배경 이미지가 실패해도 몬스터명·좌표·원문 링크는 남습니다. 지도와 몬스터명·좌표의 출처를 화면에 함께 표시합니다.

- 원본 목록·게임 지도·몬스터 이름 파일의 URL 및 SHA-256: [locations.sources.json](./locations.sources.json)
- 좌표 변환 참고: [XIVAPI MapCoordinates](https://github.com/xivapi/ffxiv-datamining/blob/master/docs/MapCoordinates.md)
- 참고 위치 재생성: `node scripts/update-locations.mjs` (캐시 우선). 인벤 목록을 새로 확인할 때는 `--refresh`를 붙이고 변경된 연결과 좌표를 검토합니다. 게임 CSV 리비전은 기존 추출기와 같습니다.

### 마수도감 원본

- 한국어 게임 데이터: [Ra-Workspace/ffxiv-datamining-ko, 66eceba](https://github.com/Ra-Workspace/ffxiv-datamining-ko/tree/66eceba69eb2398958bdb133b241a69c13672b6c/csv)
- 글로벌 게임 데이터: [xivapi/ffxiv-datamining, a67c23b](https://github.com/xivapi/ffxiv-datamining/tree/a67c23b00fe8cb254855d06b59845958b55d28f3/csv/en)
- 기능·획득 방식·교환 NPC 위치: [한국 공식 7.56 패치노트](https://www.ff14.co.kr/news/notice/view/2947)
- 아이콘 제공: [XIVAPI](https://v2.xivapi.com/)

한국어 CSV는 물리 열 순서와 세 줄짜리 헤더, 글로벌 CSV는 스키마 순서와 한 줄짜리 헤더를 사용합니다. `XBMPet`의 마수 ID, Pet ID, 아이콘 ID, 장소 타입/ID, 관련 기술 ID를 언어 간에 대조했습니다. 열 번호를 언어 간에 그대로 복사하지 않습니다.

`sources.lock.json`은 사용한 **13개 CSV**의 고정 리비전과 SHA-256을 기록합니다. 원본 파일은 저장소의 제외 폴더 `.cache/beastmaster/<revision>/`에 캐시합니다. `--refresh`는 고정 리비전을 다시 받을 뿐, 최신 패치로 자동 전환하지 않습니다. 새 버전은 리비전과 열 해석을 함께 검토해야 합니다.

정적 페이지와 데이터 추출에는 패키지 설치가 필요하지 않습니다. Node.js 22 이상에서 UI 회귀 검증까지 실행하려면 테스트 의존성을 설치합니다.

```sh
cd ffxiv/beastmaster
node scripts/update-data.mjs
npm ci --ignore-scripts
npm test
```

추출 검증에 실패하면 기존 출력 파일을 덮어쓰지 않습니다. `catalog.md`와 `data.json`은 생성 파일입니다. 이름이나 획득처를 수동으로 수정하기보다 추출 스크립트의 근거를 먼저 수정하세요.
