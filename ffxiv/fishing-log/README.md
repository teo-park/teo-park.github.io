# 세계를 누비는 어부

## 미끼 아이콘과 구매처

낚시 계획의 시작 미끼, 대체 미끼, 만능 루어와 미끼 준비 목록에서 이름을 누르면 큰 아이콘·구매/교환 가격·NPC·지역·좌표를 표시합니다. 생미끼 물고기는 기존 물고기 상세정보로 연결합니다. 팝업을 열어도 수집 기록은 변경하지 않습니다.

`bait-data.js`는 도감과 같은 Teamcraft 커밋의 `shops.json`, `npcs.json`, `recipes-per-item.json` 및 한국어 NPC·지역·아이템 명칭을 사용합니다. 전승록을 제외한 미끼 98종 중 87종에 NPC 판매/교환 자료가 있고, 22종에 제작법이 있습니다. 상점 자료가 없는 11종은 모두 제작법을 안내합니다. 판매처가 많으면 처음 5곳과 나머지를 펼치는 메뉴로 나눕니다. 상점 개방·우호도·교환 화폐의 실시간 이용 가능 여부를 판정하지 않으므로 한국 서버 게임 내 목록을 확인해야 합니다.

갱신: `node ffxiv/fishing-log/scripts/update-baits.mjs` (`--refresh`로 고정 커밋 원본을 다시 받기). 원본은 `.cache/fishing-baits/<커밋>/`에만 보관하며 필요한 항목만 배포합니다. 데이터의 Teamcraft MIT 라이선스는 기존 `licenses/Teamcraft-MIT.txt`, 게임 아이콘은 Square Enix 소유이며 XIVAPI에서 제공합니다.

기술 사용법은 [어부 스킬 안내](../fisher-skills/)에서 확인할 수 있습니다.

[어부 수첩 열기](https://teo-park.github.io/ffxiv/fishing-log/) · [한국 공식 어부 가이드](https://guide.ff14.co.kr/job/Fisher/31?type=L)

어류도감 **1,517종**, 작살도감 **289종**의 수집 기록과 낚시 조건을 확인하는 무료·비영리 팬 도구입니다. 광고·후원·유료 기능이 없습니다. 수첩·예보·접속 중 알림은 정적 HTML/CSS/JavaScript로 실행하며 회원가입·알림 서버가 없습니다.

## 수집 기록과 검색

- 어류도감과 작살도감을 구분하며, 기본 화면은 게임 데이터 순서의 **10열 × 10행, 페이지당 100종**입니다. 모바일에서도 10열을 유지하고 도감 안에서 좌우로 스크롤합니다. 마지막 페이지의 빈 칸은 수집 대상에서 제외합니다.
- 아이콘으로 체크하거나 한 페이지를 한꺼번에 체크합니다. 변경 후 실행 취소할 수 있습니다. 미수집 필터에서 체크한 칸은 즉시 사라지지 않으며, ‘체크 반영해 목록 정리’로 반영합니다.
- 이름·초성·도감 번호·아이템 ID·미끼·장소를 검색합니다. 필터를 사용하면 결과가 압축되어 **게임 페이지와 달라지므로**, 게임과 대조할 때는 필터를 초기화하세요.
- 미끼별 보기는 미수집 물고기를 시작 미끼별로 묶습니다. 생미끼가 필요하면 **같은 낚시터에서 이어지는 시작 미끼 → 생미끼** 경로를 보여 줍니다. 여러 경로가 있으면 각각 표시합니다.
- 생미끼·직감 조건 물고기는 이미 수집했어도 이름·필요 수량과 낚시 조건을 확인할 수 있습니다. 도감 체크가 실제 낚시의 직감 조건을 충족시키지는 않습니다.
- 작살도감은 미끼 대신 장소, 어영 크기, 이동 속도, 숨은 어장 조건을 표시합니다.

기록은 브라우저의 공통 저장소 `teo-ffxiv.fishing.collection.v2`에 저장합니다. 같은 주소·브라우저의 **항해일지 근해·원양·물고기 도감과 259종의 수집 체크를 양방향으로 연동**합니다. 체크·해제·실행 취소·가져오기·캡처 등록이 반영되고, 이미 열린 다른 탭과 페이지로 돌아왔을 때도 상태를 갱신합니다. 미수집 목록은 기존처럼 ‘체크 반영해 목록 정리’로 정리하며 수집 개수·체크 표시·계획과 알림 대상은 즉시 갱신합니다. 사이트 데이터 삭제·브라우저 변경 전 **수집 기록 관리 → 전체 백업 파일**로 보관하세요.

최초 사용 시 기존 어부 수첩 `teo-ffxiv.fishing.collection.v1`과 항해일지 `caughtFishLS-combined`의 수집 기록을 합칩니다. 두 원본 키는 덮어쓰지 않고, 공통 저장소에 이전 원본의 상태도 함께 기록하여 해제한 체크가 오래된 기록 때문에 다시 살아나지 않게 합니다. 이전 페이지가 기존 키를 변경하면 실제 변경분만 반영합니다. 작살·일반 어류와 목록 밖 아이템 ID도 보존합니다. 저장은 한 번의 공통 키 쓰기로 수행하고 실패 시 기존 기록을 유지합니다. 다른 기기·브라우저·원본 OceanFishing 사이트·Teamcraft 계정과의 자동 연동은 아닙니다.

## 수집도감 목록 배치

도감 번호순 보기에서 목록 아이콘을 누르면 낚시 계획과 같은 가로 열로 표시합니다. 도감 번호·수집 상태, 입질·낚아채기·입질 시간, 낚시터·지도, 출현 시간, 미끼·직감 준비, 다음 출현, 조건·수집 버튼을 한 행에 모읍니다. 페이지당 100종과 현재 페이지·검색·필터는 유지하며, 그리드로 돌아오면 기존 10×10 배치를 사용합니다. 미끼별·장소별 묶음은 기존대로 동작합니다.

- 수집한 어종도 필터에 따라 볼 수 있습니다. 미수집 필터에서 체크해도 ‘체크 반영해 목록 정리’를 누르기 전에는 행을 유지합니다. 페이지 전체 체크·실행 취소·기록 가져오기도 같은 수집 기록을 사용합니다.
- 시간은 접속 설정과 관계없는 실제 출현을 KST로 계산합니다. 클릭하면 남은 시간으로 전환하고, 상세정보에서 출현 5회를 확인합니다. 준비 어종의 하위 시간표도 함께 표시합니다. 목록 전환과 경로 선택은 알림 설정을 변경하지 않습니다.
- 여러 낚시 경로가 있으면 해당 행의 선택 상자에서 바꿉니다. 현재 지역·시작 미끼 필터에 맞는 경로만 선택하며 입질·미끼·지도·시간·펼친 조건이 선택한 경로를 따릅니다.
- 작살도감은 어영 크기·속도·숨은 어장 조건을 표시합니다. 먼바다·특수 지역·자료 미확인 어종의 시간은 상시로 추측하지 않습니다. 좁은 화면에서는 목록을 좌우로 스크롤합니다.

## 직감·생미끼 준비 어종의 출현 시간

- 계획 목록과 물고기 상세정보에서 시간·날씨 제한이 있는 직감·생미끼 어종을 하위 목록으로 표시합니다. 이미 수집했거나 검색·지역·터주 필터에서 제외된 준비 어종도 함께 표시하고, 직감 필요 마릿수·미끼·입질·낚아채기와 출현 시간을 안내합니다.
- 칠채천주는 남채어 ×3·등채어 ×3·녹채어 ×5를 표시합니다. 남채어·등채어 자체의 제한 시간을 만들지 않고, 그 아래에 시간 제한이 있는 생미끼 자채어·적채어를 연결합니다. 세 날 범고래에는 무태상어 ×2·빛무태상어 ×1의 독립적인 출현 시간을 표시합니다.
- 준비 어종은 접속 시간 필터와 관계없이 현재 또는 다음 출현 및 그다음 출현을 KST로 계산합니다. 이름이나 ‘출현 5회’를 누르면 상세 시간표에서 다섯 번째 기회까지 확인할 수 있습니다. 먼 날짜는 비동기로 계속 탐색합니다.
- 준비 어종의 시간 영역을 누르면 시작 또는 종료까지 남은 시간과 다음 출현까지 남은 시간으로 바뀌며 매초 갱신합니다. 다시 누르면 원래 날짜·시각으로 돌아갑니다. 낚시 계획·수집도감 목록·상세정보에서 같은 동작을 제공하고, 자동 갱신이나 목록 재표시에도 현재 세션의 선택을 유지합니다.
- 대상 자체에 제한이 없고 준비 어종에만 제한이 있는 경우(칠채천주 등) 계획 목록에 ‘직감·생미끼 준비 필요’ 행을 유지합니다. 각 준비 어종의 시간은 본체의 포획 가능 시간이나 직감·생미끼 준비 완료 여부를 판정하지 않습니다. 기존 알림 판정과 수집 기록은 변경하지 않습니다.
- 기존 Teamcraft 데이터의 직감·생미끼 관계를 재귀적으로 따라가며 순환을 차단합니다. 생미끼는 같은 낚시터 경로만 연결하고, 직감 어종이 다른 낚시터에만 있으면 해당 낚시터를 명시합니다. 화면 구성은 [FFXIV Fish Tracker](https://ff14fish.carbuncleplushy.com/?lang=ko)의 칠채천주·세 날 범고래 표시를 참고했으며, 해당 사이트의 코드나 자산을 가져오지 않았습니다.

## Teamcraft 기록 가져오기·내보내기

[Teamcraft 어부 수첩](https://ffxivteamcraft.com/log-tracker/FSH)의 내보내기 결과인 숫자 아이템 ID 배열을 붙여 넣거나 JSON 파일로 가져옵니다.

```json
[19956, 19933, 17560]
```

현재 도감에 해당하는 ID만 추가하며, 다른 채집 직업이나 한국 도감에 없는 ID는 제외 개수를 알려 줍니다. 기존 체크는 삭제하지 않습니다. 이 도구 자체의 백업은 향후 버전의 ID도 보존합니다.

반대로 ‘Teamcraft용 기록 복사’ 결과를 Teamcraft의 **CarbunclePlushy에서 가져오기**에 넣으면 됩니다. 해당 입력 형식은 `{"completed":[아이템 ID들]}`입니다. 양방향 모두 **추가 방식**이며 한 사이트에서 체크를 해제해도 다른 사이트의 기록을 지우지 않습니다. 계정 인증을 통한 자동 동기화는 구현하지 않았습니다.

호환 형식은 고정 Teamcraft 리비전의 [fishing-log-tracker.component.ts](https://github.com/ffxiv-teamcraft/ffxiv-teamcraft/blob/ceac70405b154d268bfc3bf6cda2776ac048a6d4/apps/client/src/app/pages/log-tracker/fishing-log-tracker/fishing-log-tracker.component.ts)의 내보내기와 `importFromCP`에서 확인했습니다.

## 도감 캡처로 등록

1. 게임 도감의 검색·필터를 해제하고 **10×10 칸 전체**를 캡처합니다. 마지막 페이지는 빈 칸도 포함하세요.
2. 수집 기록 관리 → 캡처로 등록에서 파일을 추가하거나 **Ctrl+V**로 붙여 넣습니다. 한 번에 최대 20장입니다.
3. 캡처마다 **어류/작살 종류와 게임 페이지 번호를 직접 선택**합니다. 상단 번호는 자동 인식하지 않습니다.
4. 이미지 위 ✓ 수집 / − 미수집 / ! 확인 필요 표시를 확인합니다. 칸을 누르거나 상태 버튼으로 수정합니다. 영역이 다르면 ‘아이콘 영역 조정’으로 10×10 칸을 다시 지정합니다.
5. 페이지와 상태를 확인했다는 체크 후 수집 기록에 추가합니다. 미수집·빈 칸·캡처 밖 기록은 변경하지 않습니다. 같은 종류의 같은 페이지를 중복 적용하는 것은 막습니다.

이미지는 브라우저에서만 처리하며 업로드·백업 파일에 넣지 않습니다. 물음표 아이콘 중심부의 색상·형태를 비교하고 선택 테두리는 중심 판정에서 제외합니다. 제공된 어류도감 6페이지 샘플은 **86칸 수집, 14칸 미수집**으로 검증했습니다. 작살도감도 같은 입력 방식이며, 실제 작살 캡처나 다른 UI 배율에서 같은 정확도를 보장하지 않습니다. 페이지별 첫·마지막 이름과 결과를 확인한 뒤 적용하세요.

## 낚시 계획·접속 중 알림

- **터주 전용**은 미수집 터주만, **수첩작 전용**은 일반 물고기와 터주를 함께 표시합니다. 수첩작에서는 일반 물고기만으로 좁힐 수도 있습니다. 선택한 모드·어종과 상시 알림 설정을 저장하며 기존 사용자는 터주 전용으로 시작합니다.
- ‘낚시 계획·알림’에서 요일별 **한국 시간(KST)** 접속 시작·종료를 저장합니다. 예시값은 매일 20:00–23:00이며, 저장 전 알림을 켤 수 없습니다. 금요일 22:00–02:00처럼 다음 날까지 이어지는 시간도 됩니다. 같은 시작·종료는 허용하지 않습니다.
- 미수집 어류의 시간·날씨 예보와 접속 시간의 교집합을 계산합니다. 실제 남은 시간을 기준으로 1/3/5/10분 미만 구간을 제외할 수 있습니다. 조회 날짜 상한 없이 첫 기회를 찾고, 놓쳤을 때 **내 접속 시간 안의 다음 기회**도 표시합니다. 검색·지역 필터와 ‘다음 접속 기회가 먼 순’ 정렬을 지원합니다.
- 시간·날씨 제한이 없는 어종은 **상시 낚시** 카드로 표시합니다. 접속 시간을 모두 해제해도 상시 목록은 유지하며 시간 조건 필터로 상시/시간·날씨 조건 어종을 나눌 수 있습니다. 도감 순서 정렬도 지원합니다.
- 수첩작 전용 목록에는 현재 도전 가능한 **지금**, 출현까지 **15분 전**(5분 초과·15분 이내), **30분 전**(15분 초과·30분 이내) 배지를 표시합니다. **5분 이내**부터는 남은 분을 표시하고(5분 → 4분 → 3분 → 2분 → 1분), **1분 미만**은 남은 초를 매초 갱신합니다(59초 → … → 1초 → 지금). 분 표시는 남은 시간의 분 부분이며, 툴팁에 분·초를 함께 표시합니다. 실제 출현 시작 시각으로 판별하며 접속 시작 시각을 출현 시각으로 오인하지 않습니다. 페이지 접속 중 배지는 자동 갱신되고, 종료된 기회에는 표시하지 않습니다. 알림 시점 설정과는 별개입니다.
- 조회 결과는 **물고기 한 마리당 가로 한 줄**로 표시합니다. 물고기·관심 표시, 입질 강도(!/!!/!!!)·낚아채기 종류·입질 시간·갈고리 낚시 필요 여부, 지역·낚시터, 도전 시간, 미끼·직감 준비, 다음 접속 기회, 수집 체크를 같은 순서로 비교할 수 있습니다. 좁은 화면에서는 목록 내부를 좌우로 스크롤합니다.
- 조회 결과에 필요한 시작 미끼와 직감 조건 물고기의 시작 미끼를 ‘미끼 준비 목록’에 모읍니다. 상시 어종도 포함합니다. 가능한 경로를 모두 표시하므로, 대체 미끼까지 전부 소지해야 한다는 뜻은 아닙니다. 생미끼의 상세 경로는 각 예보 행과 낚시 조건에 표시됩니다. 작살질은 기존 장소별 목록을 이용합니다.
- 예보는 **시간·날씨 조건만** 계산합니다. 직감 지속 시간·사전 준비 성공·생미끼 비축·캐릭터 능력치·물고기의 눈 효과는 계산하지 않습니다. 직감 조건이 있는 어종은 이름·수량과 조건 링크를 함께 표시하며, 별도의 준비 시간이 필요합니다. 게임 내 활성 상태나 낚시 성공을 읽지 않습니다.
- 먼바다 성취호와 디아뎀 등 특수 지역은 일반 지역 예보에서 제외합니다. 자체 시간 제한 없이 직감·생미끼의 시간에만 의존하는 어종(예: 칠채천주)은 ‘상시’로 취급하지 않고 선행 시간 별도 확인으로 분류합니다. 자료 미확인 어종은 목록 아래에서 별도로 확인할 수 있습니다. 접속 요일이 없거나 매주 반복되는 접속 시간·최소 도전 시간에 맞지 않는 어종은 계획 행을 유지하고 설정 확인을 표시합니다.
- 알림 대상은 **선택한 모드·어종의 미수집 전체** 또는 그중 별표로 고른 **관심 물고기만**입니다. 모드·어종을 바꾸면 알림 대상도 바뀝니다. **검색·지역·낚시터·시간 조건 필터는 목록만 좁히며 알림 대상을 바꾸지 않습니다.** 수집 체크·실행 취소·가져오기 후 대상이 갱신됩니다.
- ‘상시 물고기도 접속 구간마다 한 번 알림’을 켜면 상시 어종은 접속 시작 시각에 알립니다. 이미 접속 구간 중이면 처음 확인할 때 알립니다. 물고기마다 같은 접속 구간에 한 번만 알리고 같은 시각의 대상은 하나로 묶습니다. 기본값은 수첩작에서 켜짐, 터주 전용에서 꺼짐이며 모드별로 기억합니다. 이 옵션을 꺼도 상시 카드와 미끼 목록은 유지합니다. 예보 미지원 어종에는 알림을 보내지 않습니다.
- 알림은 도전 시작 0/5/10/15/30분 전입니다. 접속 시작보다 이르면 접속 시작 시각에 보냅니다. 모든 요일을 해제하면 예약 알림이 멈춥니다. 같은 시각에 예정된 어종은 하나로 묶고, 동일 기회의 중복 발송을 방지합니다.
- 알림은 **어부 수첩 페이지가 열려 있는 동안만** 계산·표시합니다. 모든 수첩 탭을 닫으면 새 알림이 멈춥니다. 서버와 Push API 구독은 사용하지 않습니다. 브라우저에서 알림 권한을 허용해야 하며 ‘시험 알림’으로 표시 여부를 확인할 수 있습니다.
- 다른 탭을 보는 동안에도 알림을 시도하지만, 브라우저의 백그라운드 타이머 제한·탭 절전·OS 알림 설정에 따라 지연·누락될 수 있습니다. 페이지로 돌아오면 현재 시간으로 다시 계산하며 이미 끝난 기회는 알리지 않습니다. [MDN 타이머 지연 안내](https://developer.mozilla.org/en-US/docs/Web/API/Window/setTimeout#timeouts_in_inactive_tabs)
- 같은 시각의 어종은 하나의 알림으로 묶습니다. 동일한 출현 기회는 브라우저 저장 이력으로 중복을 막고, Web Locks 지원 브라우저에서는 여러 탭 사이의 발송도 직렬화합니다. Web Locks 미지원 브라우저에서는 한 탭만 열어 두는 편이 좋습니다.
- 모바일의 경우 브라우저가 화면 밖으로 가면 실행이 정지될 수 있습니다. iPhone/iPad에서 알림을 지원하지 않는다고 나오면 Safari에서 홈 화면에 추가해 열어 주세요. 화면을 닫아도 동작하는 서버 푸시는 포함하지 않습니다.

접속 시간·관심 물고기는 `teo-ffxiv.fishing.plan.v1`, 알림 켜짐 상태는 `teo-ffxiv.fishing.notifications.v1`, 중복 방지 이력은 `teo-ffxiv.fishing.notifications.sent.v1`에 저장합니다. 설정·대상 물고기·수집 기록을 외부로 전송하지 않습니다. 수집 체크·실행 취소·가져오기와 다른 탭의 변경이 알림 대상에 반영됩니다. 사이트 데이터를 지우기 전에 수집 기록을 백업하세요.

Service Worker는 모바일 알림 표시와 알림 클릭 후 해당 물고기의 상세 정보를 여는 용도로만 사용합니다. 페이지 밖에서 예보를 계산하거나 별도의 서버 구독·발송 작업을 수행하지 않습니다.

### 기한 없는 조회와 행별 조건

계획 목록에는 날짜 상한을 두지 않습니다. 처음 30일을 계산한 뒤 날짜가 없거나 다음 기회를 더 찾아야 하는 어종만 30일 단위로 계속 탐색합니다. 30일은 계산 묶음이며 결과를 숨기거나 탐색을 종료하는 상한이 아닙니다. 다음 날짜를 찾는 동안에도 물고기는 행에 표시됩니다. 작업을 짧게 나누어 화면 조작을 허용하고, 페이지가 보이지 않으면 추가 계산을 멈춥니다. 분 단위 갱신에서 먼 날짜 조회의 진행도를 이어받으며, 접속 설정이나 낚시 경로가 달라지면 해당 진행도를 재사용하지 않습니다. 다음 해의 날짜에는 연도를 함께 표시합니다.

목록의 ‘조건’ 버튼은 행 바로 아래에 상세 정보를 펼칩니다. 여러 어종을 함께 열 수 있고 다시 누르거나 펼친 영역의 ‘접기’로 닫습니다. 날짜 갱신 중에도 열린 영역과 교환 방생 비교 선택을 유지합니다. 도감의 상세보기와 물고기 이름 링크는 기존 팝업을 사용합니다.

### 상세 출현 시간 5회

물고기 이름이나 계획 행의 ‘출현 5회 보기’를 누르면 상세창 위쪽에서 가까운 시간 5회를 확인합니다. 기본 ‘전체 출현’은 실제 시간·날씨 조건에 맞는 출현 구간, ‘내 접속 시간’은 저장된 요일·시간과 최소 도전 시간을 적용한 구간입니다. 현재 열린 구간도 포함하며 한국 시간(KST)으로 표시합니다. 겹치거나 연속되는 낚시 경로는 하나의 기회로 합칩니다.

`forecast.startTimeline`은 선택한 한 어종만 30일씩 계산하며 다섯 번째 기회까지 기간 상한 없이 이어갑니다. 상시 어종이나 지원하지 않는 조건에는 임의의 날짜를 만들지 않습니다. 상세창을 닫으면 추가 계산을 취소하고, 숨겨진 탭은 계산을 멈춥니다. 직감·생미끼의 선행 조건은 별도 준비해야 하며 실제 게임 상태는 읽지 않습니다. 이 보기의 전환은 수집 기록과 알림 설정을 바꾸지 않습니다.

### 입질 시간 관측 자료

2026-09-09부터 수집한 Teamcraft 공개 집계 스냅샷입니다. 포테우카 등 3종 경로 보완에 해당하는 배치는 2026-09-10 다시 조회했습니다. 기본 경로 2,732개 중 2,703개에 입질 시간이 있고, 다른 미끼를 사용한 관측도 보존하여 전체 14,253개 어종·낚시터·미끼 조합을 비교에 사용합니다. 클라이언트는 정적 파일만 읽으며 개인 낚시 기록을 요청하거나 전송하지 않습니다.

Teamcraft의 미끼별 입질 통계와 동일하게 1초 초과·600초 미만의 정수 초 구간 중 관측 3건 이상인 구간만 사용합니다. 원자료가 버림한 초이므로 최댓값에는 1초를 더해 전체 구간을 감쌉니다. 예를 들어 10초부터 14초 구간의 관측은 ‘약 10–15초’로 표시합니다. 이는 최소·최대 관측 범위이며 신뢰구간이나 보장된 입질 제한 시간이 아닙니다. 밑밥·루어·날씨·패치별 관측을 분리하지 않으며, 통계가 없는 조합은 다른 미끼나 낚시터의 값을 가져오지 않고 ‘시간 미확인’으로 둡니다.

2026-09-10부터 같은 스냅샷에 중앙값·평균을 추가했습니다(`schemaVersion: 2`). 각 1초 구간을 `t + 0.5`초로 대표하고 관측 건수로 가중하여 평균과 중앙값을 계산한 뒤 소수점 한 자리로 반올림합니다. 중앙값은 가운데 관측 순위를 사용하며, 짝수 표본은 가운데 두 값의 평균을 씁니다. 전체 최솟값·최댓값의 중간값이나 구간별 동일 가중 평균이 아닙니다. 위 3건 이상 구간 필터를 통과한 표본만 사용하므로 원본 전체 어획의 정확한 실측 평균으로 해석하면 안 됩니다. 기존 관측 범위·건수·수집 시각은 보존합니다.

계획 목록과 생미끼 준비에는 중앙값을 먼저 표시하고 마우스를 올리면 평균·범위·표본 수를 함께 보여줍니다. 조건 펼침의 비교에는 중앙값과 범위를, 전체 상세·대체 미끼·생미끼 설명에는 중앙값·평균·범위를 표시합니다. 중앙값은 긴 꼬리의 영향을 줄여 대표 시간을 파악하는 참고값이며, 교환 방생 비교와 단독 입질 구간 계산은 계속 전체 범위를 사용합니다. 통계가 없는 조합이나 이전 형식에는 중앙값·평균을 임의로 만들지 않습니다.

입질 통계 갱신: 저장소 루트에서 `node ffxiv/fishing-log/scripts/update-bite-times.mjs --refresh`. 로컬 캐시는 `.cache/fishing-log/bite-times/`이며 `--refresh` 없이 실행하면 캐시를 재사용합니다. 실패 시 기존 배포용 파일을 교체하지 않습니다.

## 터주 유형별 공략 링크

낚시 계획의 **조건**, 물고기 상세정보와 장소·미끼별 목록에서 해당하는 [유형별 공략](../fisher-skills/big-fish/)을 새 탭으로 엽니다. 준비와 본 낚시를 구분하며 여러 유형을 함께 표시합니다. 단일 생미끼의 2·3번은 **생미끼 확보 · 방법 비교**로 연결하고 어느 쪽이 최적이라고 자동 판정하지 않습니다. 일반 물고기·먼바다 어종에는 이 링크를 표시하지 않습니다.

2026-09-10에 일반 낚시터 터주 335종을 점검했습니다. 직접 낚시 223종, 단일 생미끼 96종, 연속 생미끼 16종이며 직감 재료의 종류에 따라 준비 유형을 추가합니다. 저글링은 공략에서 확인한 본 낚시 16종·준비 단계 2종만 반영합니다. 일반 어종이지만 확보가 어려운 조각가·팔라이나를 요구하는 스테타칸투스·별고래에는 6·7번을 함께 표시합니다. 관측 기록만 있는 저글링 후보는 반영하지 않습니다.

기본 연결은 기존 Teamcraft 자료를 사용하며, [Carbuncle Plushy 고정 리비전](https://github.com/icykoneko/ff14-fish-tracker-app/blob/8a5012b276f815d5b6c5034b175b49df61dc2b64/private/fishData.yaml)의 생미끼 순서·직감 재료 및 수량과 대조했습니다. 저글링·희귀 직감의 판정 근거는 [strategy-review.json](./strategy-review.json)에 해당 [Fruity Snacks 공략](https://afishersguidetoeorzea.carrd.co/) 주소와 요약을 기록합니다. 전체 공략 원문은 배포하지 않습니다.

데이터 갱신 뒤 저장소 루트에서 `node ffxiv/fishing-log/scripts/build-strategy-links.cjs`를 실행하여 `strategy-links-data.js`를 생성합니다. 생미끼 연결이 불완전하거나 확인된 저글링이 현재 경로와 달라지면 생성을 중단하고 재검토합니다.

## 데이터 범위와 한계

2026-09-08에 아래 리비전으로 생성한 스냅샷입니다. 한국 게임 데이터의 `FishParameter.IsInLog`와 `SpearfishingItem.IsVisible`로 도감 범위를 정합니다. `IsHidden`인 희귀 어종도 어류도감에 포함하며, 게임 행 순서대로 배치합니다.

**원본에서 조건이 없던 39종 중 일반 필드 어종 3종을 공개 관측으로 보완했습니다. 나머지 36종은 모두 먼바다 어종이며 별도의 항해일지에 미끼 자료가 있습니다.** 이 수첩의 Teamcraft 경로 자료에는 조건이 없어 상세보기에서 항해일지로 안내하고, 일반 필드의 시간·날씨 예보에 넣지 않습니다. 낚시터만 확인된 경우 미끼·날씨 등을 추정하지 않습니다. 공개 자료의 한국/글로벌 업데이트 차이로 게임 표시와 차이가 날 수 있습니다.

표시된 미끼는 확인된 경로이며 가능한 모든 미끼의 목록이나 실제 입질 성공률 순위가 아닙니다. 일반 물고기의 추천은 아래 어획 비중 보정을 적용하며, 특수 조건 경로는 원자료를 유지합니다. 상세 조건의 시간은 에오르제아 시간(ET), 낚시 계획의 예보 날짜는 한국 시간(KST)입니다. 지역 날씨는 공개된 결정적 계산식으로 예측하며 게임 서버나 캐릭터의 능력치·직감 상태를 읽지 않습니다.

## 개발·검증

저장소 루트를 정적 서버로 열면 `/ffxiv/fishing-log/`에서 실행됩니다. 배포에는 빌드나 패키지 설치가 필요 없습니다.

```sh
cd ffxiv/fishing-log
npm ci --ignore-scripts
npm test
node scripts/update-data.mjs
node scripts/update-weather.mjs
```

갱신 스크립트는 명시된 고정 리비전에서 공개 자료를 가져와 `data.js`를 생성하고 캐시를 저장소의 `.cache/fishing-log/`에 둡니다. `--refresh`는 같은 리비전의 파일을 다시 받습니다. 실제 새 데이터로 갱신하려면 리비전을 검토·수정해야 합니다.

테스트는 도감 범위·정렬, 같은 장소의 생미끼 경로, 알 수 없는 조건, Teamcraft/백업 호환, 저장 실패·실행 취소·다른 탭의 변경, 10×10 렌더링, 캡처 검토·중복 페이지·마지막 빈 칸·붙여넣기·취소를 확인합니다. 개인 샘플은 저장소에 포함하지 않으며 `FISH_SCAN_FIXTURE` 환경 변수로 로컬 RGBA 픽셀과 정답 메타데이터가 있는 JSON 경로를 주면 별도 인식 검증도 실행합니다.

### 대체 미끼와 만능 루어

- 같은 어종·낚시터의 Teamcraft 입질 관측 기록에서 기본 미끼와 만능 루어를 제외한 대체 미끼 한 종류를 표시합니다. 보정 대상 경로는 아래 보정 순위를 우선하고, 보정 자료가 없는 조합만 기존 입질 표본 수 순서를 사용합니다. 입질 시간 자료가 없는 미끼를 대체 미끼에 넣거나 다른 미끼의 시간을 가져오지 않습니다.
- 만능 루어는 별도로 사용 기록 유무를 표시합니다. 자료가 없는 조합은 미확인이며 사용 불가로 단정하지 않습니다. 기본 미끼가 만능 루어인 경우 기본 미끼로 표시합니다.
- 생미끼 어종의 장착 미끼 기록은 직접 낚시 가능의 근거로 사용하지 않습니다. 같은 낚시터의 생미끼 경로에서 처음 잡는 물고기의 시작 미끼 대체품만 보여 주고 생미끼 단계를 유지합니다.
- 펼친 조건에는 대체품별 관측 입질 시간을 표시하며, 입질 비교는 해당 경로에 표시된 추천 미끼를 기준으로 합니다.

### 미끼 추천 보정

`bait-catches.js`는 2026-09-10에 가져온 Teamcraft 공개 집계 스냅샷입니다. 낚시터 333곳, 낚시터·미끼 조합 3,777개의 전체 어획 수와 어종별 어획 수를 담습니다. 많이 사용한 미끼에 목표 어획 건수도 몰리는 편향을 줄이기 위해 **목표 어획 수 / 동일 낚시터·동일 미끼의 전체 어획 수**를 비교합니다. 도감에 없는 어종도 전체 어획 수에 포함합니다.

- 자료: [Teamcraft 미끼별 어획 쿼리](https://github.com/ffxiv-teamcraft/ffxiv-teamcraft/blob/ceac70405b154d268bfc3bf6cda2776ac048a6d4/apps/client/src/app/pages/db/service/fish-data.gql.ts)의 `baits_per_fish_per_spot`, [공개 집계 API](https://gubal.ffxivteamcraft.com/graphql). 기존 [MIT 고지](./licenses/Teamcraft-MIT.txt)를 함께 제공합니다. 개인 낚시 기록·계정 정보를 요청하지 않습니다.
- 범위: `aLure=0`, `mLure=0`인 기록만 사용합니다. 루어 횟수 미확인·사용 기록, 음수 아이템 ID인 놓친 어획, 생미끼 물고기 ID는 제외합니다. 입질 시간 구간 필터는 적용하지 않으므로 **입질 표본 수와 어획 건수가 다릅니다**. 각 배치의 실제 수집 시각은 파일에 보존합니다.
- 점수: 어획 비중의 [Wilson 구간](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm) 하한(`z=1.96`)을 보수적인 비교 점수로 씁니다. 전체 100건·목표 10건 이상인 미끼를 우선합니다. 기존 미끼를 포함해 최소 두 미끼가 기준을 충족해야 자동 변경을 검토합니다.
- 변경: 최고 점수 미끼의 하한이 기존 미끼의 상한보다 높고, 관측 비중 차이가 2%p 이상일 때만 추천을 변경합니다. 차이가 불명확하거나 표본이 적으면 기존 Teamcraft 미끼를 유지합니다. 이 문턱은 잦은 변경을 줄이기 위한 도구의 정책이며 게임의 공식 계산식이나 최적 효율 보장이 아닙니다.
- 보호 범위: 터주·전설어·시간·날씨·직감·갈고리 낚시·루어 기술·먼바다 시간 조건·작살·검증되지 않은 경로는 자동 변경하지 않습니다. 생미끼 경로는 중간 어종을 그대로 유지하고, 조건 없는 첫 물고기의 시작 미끼만 보정할 수 있습니다. 같은 낚시터에서 직접 낚시와 생미끼 경로가 함께 있는 어종도 원자료를 유지합니다.
- 반영 범위: 목록·미끼 필터·미끼별 묶음·준비 목록·첫 생미끼·입질 시간·비교 어종이 동일한 추천 경로를 사용합니다. 원자료 `data.js`는 변경하지 않으며 기존 미끼 ID도 보존합니다. 조건의 ‘미끼 추천 근거’에서 미끼별 분자·분모·관측 비중·보정 점수를 확인할 수 있습니다.

**실제 입질 확률이나 시간당 효율은 아닙니다.** 전체 시도 수가 아닌 성공한 어획의 구성비입니다. 특정 입질을 취소한 기록, 교환 방생·한결같은 마음, 시간·날씨 선택, 능력치·패치 차이 등의 편향은 집계만으로 제거할 수 없습니다. Wilson 점수는 적은 표본을 과대평가하지 않기 위한 장치이며, 이 편향을 없애거나 실제 성공률의 신뢰구간을 보장하지 않습니다. 표범참바리의 경우 고등어 살 208/988(21.1%), 새우 떡밥 2,953/20,333(14.5%)으로 고등어 살을 유지합니다. 기존 178건·2,675건은 각각 별도 입질 시간 표본입니다.

갱신: 저장소 루트에서 `node ffxiv/fishing-log/scripts/update-bait-catches.mjs --refresh`. 캐시는 `.cache/fishing-log/bait-catches/`에 저장합니다. 모든 배치 수집에 성공한 뒤 배포 파일을 교체하며, 도감과 Teamcraft 리비전이 맞지 않거나 파일을 불러오지 못하면 보정을 적용하지 않습니다.

### 계획 행의 간단한 조건과 남은 시간

- 계획의 조건 펼침은 현재 행의 낚시터·경로만 표시하며 출현 조건, 미끼, 같은 입질 비교를 가로로 배치합니다. 이름·아이콘·수집 버튼과 다른 낚시터는 중복하지 않습니다. 전체 상세 버튼에서 기존 전체 정보를 볼 수 있습니다.
- 경쟁 어종은 먼저 4종을 표시하고 나머지는 펼쳐 볼 수 있습니다. 교환 방생 비교의 계산은 접힌 어종까지 전부 포함하며, 비교 선택과 펼침은 갱신 시 유지됩니다. 행의 경로가 바뀌면 조건도 새 경로로 갱신합니다.
- 도전 시간 셀을 누르면 시작까지 또는 종료까지의 남은 시간으로 전환합니다. 화면을 보고 있는 동안 초 단위로 갱신하고, 다시 누르면 날짜·시각을 표시합니다. 상시·예보 미확인 행은 전환 대상에서 제외합니다.
- 기본 미끼에도 관측 건수를 표시하며, 생미끼 경로의 시작 미끼 건수는 첫 생미끼 물고기를 잡은 기록입니다.

- !!! 확장 비교에서도 개별 물고기의 원래 입질 기호를 유지합니다. 확장된 경쟁 목록 전체를 교환 방생 후보와 관측상 단독 입질 구간 계산에 함께 사용합니다. 대상이 일반 !·!!이거나 !!!의 낚아채기가 미확인인 경우 기존의 같은 입질 비교를 유지합니다.


### 루어 메시지 필수 표시

- Teamcraft 경로의 양수 `mLure` / `aLure` 조건을 계획 목록에서 스킬 아이콘·이름·‘메시지 필요’ 배지로 표시합니다. 배지는 어부 스킬 안내의 루어 설명으로 연결하며, 마우스를 올리면 자료상 사용 횟수와 특수 출현 메시지 확인 안내가 나옵니다. 일반 물고기의 임의 추천 루어와 혼동하지 않도록 실제 경로 조건만 사용합니다.
- 생미끼 및 직감 준비 물고기의 루어 조건은 같은 낚시터 경로에서 확인하고 해당 준비 물고기의 이름과 함께 표시합니다. 대상 어류 자체의 조건으로 잘못 표시하지 않습니다. 조건 펼침과 상세보기에도 ‘특수 메시지 필요’를 명시합니다.
- 횟수만 채우거나 일반적인 소형·대형 확정 유인 메시지를 띄웠다고 대상 어종이 확정되는 것은 아닙니다. 특수 출현 메시지의 동작 설명: [Fruity Snacks의 공개 연구 정리](https://na.finalfantasyxiv.com/lodestone/character/12300440/blog/5420089). 개별 출현 문구를 추측해 번역하지 않습니다.

### 먼바다 별도 분류

- 낚시 계획·알림, 미끼 준비, 지역 선택, ‘예보가 없는 물고기 확인’에는 먼바다 259종을 포함하지 않습니다. 항해일지와 먼바다 수집 도감으로 이동하는 링크를 제공합니다. 일반 필드의 선행 조건 확인 대상 6종은 그대로 남습니다.
