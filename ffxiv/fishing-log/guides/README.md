# 터주 공략 자료와 작성 기준

2026-09-10 확인. 현재 한국어 수첩의 패치 7.55까지, 일반 해역 터주 **335종**과 그 안의 터주왕 **36종**을 대상으로 한다. `big` 플래그에 포함된 먼바다 어종은 별도의 항해일지 범위이므로 제외한다.

## 표시를 구분하는 이유

- **공략 대조**: 공개된 개별 공략에서 교방 대상·준비 시점·특수한 기술 순서 등의 예외를 확인해 `notes.cjs`에 기록한 어종. 기본 경로와 일반 기술 안내에는 조건으로부터 도출한 내용도 포함된다.
- **조건 기반 계획**: 해당 어종의 실제 미끼 경로·직감 재료·입질·낚아채기 조건에 공식 기술 효과를 적용해 작성한 계획. 개별 최적 공략을 확인했다고 주장하지 않는다.
- **관측 기반 교방 후보**: 별도 교방 공략이 없는 경우의 제한적인 후보. 같은 미끼·입질 계열로 기록된 일반 어종을 비교하고, 목표·생미끼·직감 재료를 제외한다. 최소 전체 100건·후보 10건의 기록을 요구한다. 포획량은 취소한 입질을 포함한 전체 입질 확률이 아니며, 시간·날씨·선택적 낚아채기에 따른 편향이 남는다.

개별 공략이 없는 어종에 출처를 꾸며 붙이지 않는다. 관련 터주왕의 글에서 준비 어종을 다루는 경우에는 **관련 어종 공략**이라고 표시하며, 부모 어종의 직감·교방 계획을 그대로 상속하지 않는다. 어종별 원문 링크가 있다는 것과 모든 세부 전략을 검증했다는 것도 구분한다. 현재 세부 전략 대조 191종, 개별·관련 공략 연결 191종이며, 전체 335종에는 조건에 따른 계획을 제공한다.

## 출처

1. [한국 공식 가이드 · 어부 기술](https://guide.ff14.co.kr/job/Fisher/31?type=L): 기술 효과와 공식 한국어 명칭·레벨. 인내/대물 낚시의 월척 효과를 터주 입질 확률 증가로 취급하지 않는다. 인내의 페널티, 생미끼를 끊는 기술, 숙련 낚시꾼의 적용 시점을 확인했다.
2. [Teamcraft](https://ffxivteamcraft.com/log-tracker/FSH): 수첩의 낚시터·미끼·생미끼·직감·날씨 조건. 기존 `data.js`와 동일 리비전을 사용하며 공략을 위해 조건·일정·수집 기록을 변경하지 않는다. 미끼 관측량의 추가 한계는 `../scripts/update-bait-catches.mjs`와 미끼 추천 기준 표시 참고.
3. [Fruity Snacks · A Fisher’s Guide to Eorzea](https://afishersguidetoeorzea.carrd.co/): ARR부터 Dawntrail까지 6권의 어종별 공략과 기술 설명. 개인 공략의 절차상 예외를 대조했다. 문서 전문·번역본·이미지는 재배포하지 않는다. 원문 링크·권수·확인일은 `references.json`에 있으며, 일부 문서는 여러 어종이나 여러 레벨의 전략을 함께 설명한다.
4. [꼬막킴 · 7.55 터주왕 공략](https://www.inven.co.kr/board/ff14/4467/13958): 2026-08-21 게시, 본문 2026-09-04 수정 표시. 최신 터주왕 6종의 전용 루어 메시지, 직감 시점, 생미끼 준비를 교차 확인했다. 글 자체가 최적화 중이라고 명시하고 있으므로 ‘확정 최적화’로 표시하지 않는다.
5. [Carbuncle Plushy 공개 조건 자료](https://github.com/icykoneko/ff14-fish-tracker-app/blob/8a5012b276f815d5b6c5034b175b49df61dc2b64/private/fishData.yaml): 어종 도입 패치와 제공된 직감 지속 시간. 사용한 리비전을 고정했다. MIT 고지는 `Carbuncle-Plushy-LICENSE.txt`에 보존한다. 해당 파일에 아직 없는 최신 직감 시간은 위 개별 공략과 대조했다.

## 확인한 중요한 차이

- 교방은 **직감 전/후**, **첫 생미끼 준비/본 낚시**, **루어 사용/미사용**에 따라 다르다. 아직 모으지 않은 직감 재료를 제외하거나 생미끼로 낚은 물고기에 일반 교방 절차를 적용하지 않는다.
- 같은 `!!!`이라도 낚아채기 계열과 경쟁 어종이 다르다. 루어를 항상 추가하는 것이 최선은 아니다. 짧은 직감에서는 시도 횟수·재준비 GP를 먼저 고려해야 한다.
- 대물 낚시는 드문 월척 생미끼를 기다릴 때 유용하다. 연속 생미끼에는 인내·숙련 낚시꾼·보관의 역할을 구분한다. 이미 떠 있는 프록에 대물 낚시·인내·밑밥을 쓰는 순서는 피한다.
- 전용 루어 메시지를 일반 크기 확정 메시지로 대신하지 않는다. 최근 공략의 추정 입질 확률·갱신 확률은 확정 수치로 가져오지 않았다.
- 관측 시간은 미끼와 루어/밑밥 사용 시점에 의존한다. 특정 미끼의 공략 시간을 다른 미끼나 수첩의 일반 시간 통계와 섞어 확정 저격으로 안내하지 않는다.
- 오래된 공략의 기술 명칭·레벨·인내 설명과 최신 공식 효과가 충돌할 경우 공식 효과를 우선한다. 단순히 모든 어종에 인내 2·삼중 낚아채기를 권하지 않는다.

## 갱신

`references.json`은 공개 문서를 대조한 메타데이터이고 `notes.cjs`는 검토한 예외만 담는다. 자동으로 문장 속 물고기 이름을 교방 대상으로 추출하지 않는다. 부정문, 다른 단계의 물고기, 대안 미끼를 잘못 가져올 수 있기 때문이다.

```sh
node ffxiv/fishing-log/scripts/build-strategies.mjs
cd ffxiv/fishing-log
npm test
```

빌드는 자료 리비전, 범위, 물고기 ID와 교방 대상의 낚시터를 검증한다. 수첩 자료가 바뀌면 범위·조건을 다시 대조해야 빌드할 수 있다. 브라우저 역시 수첩과 공략의 리비전이 다르면 오래된 공략을 적용하지 않는다.
