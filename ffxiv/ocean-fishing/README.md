# 먼바다 낚시 개인용 수정판

직접 주소로 사용하는 근해·원양 항로 페이지입니다. 포털 메뉴와 사이트맵에 연결하지 않으며 HTML에 `noindex, nofollow, noarchive`를 표시합니다. 접근 제한은 없으므로 주소를 알면 누구나 볼 수 있습니다.

## 변경점

- 나눔스퀘어라운드, 기본 13px 글자, 물고기 아이콘 30px, 좁은 표 여백.
- 항로의 물고기 행에서 잡음 체크와 해제, 잡은 물고기 숨기기.
- 직감·생미끼 의존 관계를 따라 필요한 물고기를 계속 표시하고 `조건용`으로 설명.
- 일반 구간에서 한국어 이름이 `유령`으로 시작하는 물고기는 잡음·대어 집중 필터와 관계없이 미끼 확인용으로 계속 표시.
- 선상과제용 물고기군 필터. 선택한 종류는 이미 잡았어도 표시하며 직감·생미끼 조건을 연쇄적으로 유지합니다. `전체`로 돌아오면 원래의 잡음 숨김 설정을 복원합니다. 물고기군 선택 중에는 완료 항로 숨김을 일시적으로 해제합니다.
- 고득점 후보 옵션은 이중/삼중 낚아채기를 선택하여 현재 구간의 일반·환해류별 최소 획득 점수 상위 3종(동점 포함)을 보여줍니다. 기본 점수 × 낚는 수로 계산하며 보너스·GP·입질 확률은 고려하지 않습니다. 원본과 동일하게 수량이 비어 있으면 이중 3–4마리, 삼중 5–7마리를 사용합니다. 과제 필터와 고득점 옵션은 번갈아 사용합니다.
- `checklist/`에서 근해 140종·원양 119종을 해역별로 확인하고 체크할 수 있습니다. 항로 페이지와 같은 저장값 및 가져오기·내보내기 형식을 사용하며, 같은 물고기의 체크를 해제하면 원본 상세 키의 체크도 함께 해제됩니다.
- 목표를 잡으면 불필요해진 조건 물고기도 숨김. 같은 어종의 여러 행은 함께 처리.
- 근해·원양 체크를 브라우저에 저장하고 같은 출처의 탭 간 변경을 반영.
- 원본 데이터·항로 계산을 유지하며 외부 분석 스크립트는 사용하지 않음.

원본 사이트와 출처가 달라 원본 사이트의 브라우저 저장값은 자동으로 이전되지 않습니다.

원본 체크리스트의 Export로 내려받은 `checklist-export.json`을 항로 화면의 **기록 가져오기**로 선택하면 근해·원양 기록을 함께 합칩니다. 원본의 어종별 키와 장소·시간·미끼별 상세 키를 모두 읽으며 같은 어종에서 하나라도 체크되어 있으면 잡은 것으로 봅니다. 기존 기록을 지우지 않도록 가져온 파일의 `true` 기록만 합칩니다. **기록 내보내기**로 개선판의 근해·원양 전체 기록을 백업할 수 있습니다. 파일은 브라우저 안에서 처리하며 서버로 전송하지 않습니다.

## 관리

`scripts/collection.js`는 의존 관계와 저장 상태, `collection-ui.js`는 체크·숨김 UI, `css/compact.css`는 크기와 간격을 담당합니다. 원본 `displayStops.js`와 `gFuncs.js`에 표시 연결부가 있습니다. 원본 행은 표시하면서 수정되므로 다시 그릴 때 항상 `cleanedDataObjBK`의 복사본을 사용합니다.

`fishdata/`의 한국어 CSV는 현재 시점의 복사본입니다. 데이터 갱신 후 다음 명령으로 직감·생미끼 참조를 확인하세요.

```sh
node --test ffxiv/ocean-fishing/tests/collection.test.cjs
```
