# 항해일지

먼바다 낚시 시간표·수집 기록·낚시 전략을 확인하는 무료·비영리 팬 도구입니다. `ffxiv/ocean-fishing/` 아래 정적 파일로 배포합니다. 비밀번호 없이 이용할 수 있으며 메인 도구 목록과 사이트맵에서 연결합니다.

화면·시간표·검색·필터·기록 관리가 자체 JavaScript와 CSS로 동작합니다. 현재 배포 파일에서 OceanFishing.Boats의 실행 코드, jQuery, DataTables, Bootstrap, Moment, 기존 사이트의 물고기군 도장 이미지를 제거했습니다. 게임·커뮤니티 **자료의 출처와 이용 조건은 프로그램과 별개**이며 아래에 명시합니다. 이전 커밋을 포함한 Git 이력을 지우는 작업은 아닙니다.

## 입장과 저장

- 루트 `index.html`에서 근해 수첩·원양 수첩·물고기 도감을 선택합니다. 각 수첩의 직접 주소도 바로 열립니다.
- 기존 `?next=ruby` 같은 입장 링크는 해당 수첩으로 연결합니다. 허용된 세 경로 외의 주소로 이동하지 않습니다.
- 수집 기록은 **세계를 누비는 어부**와 공통 키 `teo-ffxiv.fishing.collection.v2`를 사용합니다. 같은 주소·브라우저에서 근해·원양·물고기 도감과 어부 수첩의 259종을 아이템 ID로 연결하며 체크·해제·실행 취소·가져오기·캡처 등록을 양방향 반영합니다. 열린 다른 탭과 페이지 복귀 시에도 갱신됩니다. 항로 준비 미끼와 도감 채우기 필터도 연동된 기록을 사용합니다.
- 최초에는 기존 `caughtFishLS-combined`와 어부 수첩 `teo-ffxiv.fishing.collection.v1`의 수집 기록을 합치고, 두 원본 키는 보존합니다. 이후 원본의 실제 변경분만 적용해 해제한 체크의 재등장을 막습니다. 항해일지의 알 수 없는 이름 기록과 어부 수첩의 작살·일반 어종·목록 밖 ID를 보존합니다. 공통 기록은 단일 키에 한 번 저장하며 오류 시 양쪽 기록을 일부만 변경하지 않습니다. JSON 내보내기 형식은 이전 항해일지와 동일합니다. 로컬 ZIP·다른 브라우저·원본 사이트·Teamcraft는 출처가 달라 자동 연동되지 않으므로 내보낸 JSON을 가져오세요.
- 비밀번호 해제는 기존 수집 기록에 영향을 주지 않습니다. 개인 수집 데이터는 배포 파일에 포함하지 않습니다.

## 화면과 기능

- 다른 도구와 같은 `ffxiv/theme.css`를 사용하는 짙은 남색·하늘색 디자인. 공통 도구함 로고·상단 메뉴와 카드·입력창·버튼 스타일을 맞추고, 수집 기록 관리는 각 수첩 제목 옆에 배치했습니다. 본문·숫자 모두 공통 LINE Seed KR(보조: 나눔스퀘어라운드)이며, 안내·표·버튼·모바일 글씨도 최소 10pt로 표시합니다.
- 출항 시간표 → 수집 현황·낚시 목적 → 세 구간의 일반/환해류 물고기 순서로 배치했습니다. 모바일에서는 목적 선택이 물고기 목록 위로 이동하고 넓은 표만 안에서 가로로 스크롤합니다.
- 첫 출항 시간은 항상 보이며 이후 시간표는 기본 접힘입니다. 출항 후 1시간까지는 접수가 끝난 항로도 첫 줄에 유지해 낚시 중인 항로를 계속 볼 수 있습니다. 시간을 선택하면 항로와 세 구간 정보가 바뀝니다.
- 각 지역 탭에는 환해류 유도 물고기의 권장 시작 미끼와 해당 항로의 시간대에 만날 수 있는 터주·전설어 이름을 표시합니다. 이미 잡은 터주·전설어는 `(수집완료)`를 붙이며, 시간표의 전설어 목록에도 같은 상태를 표시합니다. 물고기 목록을 필터링해도 이 안내는 유지되고 체크·해제·가져오기 시 바로 갱신됩니다.
- 터주는 일반 구간의 직감 대상 4성 물고기, 전설어는 환해류의 직감 대상 5성 물고기로 분류합니다. 원본 이름의 미끼 접두어에만 의존하지 않아 플라코두스·청옥룡도 포함합니다. 각 지역에 터주·전설어·환해류 유도 물고기가 한 종씩 있는지 검증합니다. 환해류 유도 물고기는 번역된 이름과 관계없이 식별합니다. 분류와 유도 미끼의 의미는 [데이터 제작진의 설명](https://ffxiv.oceanfishing.boats/FAQ/)을 참고했습니다.
- `전체 보기`, `도감 채우기`, `선상과제/업적`, `고득점` 중 목적을 고르면 관련 옵션만 나타납니다.
- 잡은 물고기를 숨겨도 미획득 목표에 필요한 직감·생미끼 조건을 연쇄적으로 유지합니다. 일반 구간의 환해류 유도 물고기와 이름이 `유령`·`환해`로 시작하는 물고기는 미끼 확인용으로 계속 표시합니다. 수집·선상과제·전설어 조건·미끼 필터에서도 유지하며 원양의 환해 놀래기·환해 구렁이·환해 골설어를 포함합니다.
- 선상과제/업적은 물고기군을 체크박스로 복수 선택하며, 이미 수집한 대상도 표시합니다. 업적 12종의 한 항해 목표 수량·개인/파티 구분을 관리합니다. 가오리 25마리, 새우·갯가재 각각 50마리는 개인 기록이며 나머지는 소속 파티 합산입니다. 물고기군은 게임 데이터의 분류로 연결해 새우와 갯가재를 구분합니다.
- 시간표의 `업적 추천 · 상어 · 파티 200마리` 표시는 공략에서 확인한 항로·시간대 조합을 사용합니다. 세 구간 공통 어종 교집합 판정을 제거했습니다. 추천 외에는 공략상 대체 항로, 일부 대상 어종만 출현하는 항로, 대상 없음으로 구분합니다. 출현만으로 달성 가능성을 보장하지 않습니다.
- 업적작 계획을 펼치면 현재 항로의 세 구간별 대상 어종·주력 표시·미끼·입질/낚아채기·입질 시간·이중/삼중 수량·직감/생미끼 조건을 보여줍니다. 어종 출현은 구간 시간대에 맞게 걸러지며 수집 상태나 표의 추가 필터와 독립적입니다. 추천 항로에서만 환해류 유도/회피/날씨별 운영을 안내해 다른 시간대에 공략을 잘못 적용하지 않습니다. 실시간 날씨와 이번 항해 포획 수는 자동으로 읽지 않습니다.
- 가장 가까운 추천 출항으로 이동하면 해당 업적의 물고기군과 항로가 함께 선택됩니다. 전체 12일 반복 주기에서 아직 접수 가능한 시간을 찾습니다. 복수 선택은 어종 합집합이며 업적 동시 달성 추천이 아닙니다. 복어·가오리처럼 같은 항로에서 환해류 운영이 충돌하면 구간과 업적별 차이를 표시합니다.
- 표는 물고기·입질·권장 미끼·기본/이중/삼중 점수·시간대·날씨·물고기군·미끼별 입질 시간을 항상 표시합니다. 미끼·시간대·물고기군은 읽을 수 있는 이름으로 표시합니다. 항로 전체의 조건을 계산한 뒤 구간별로 나누며, 추가 필터에서도 필요한 조건 물고기를 유지합니다.
- 일반 구간·환해류 제목 아래에는 현재 표시 중인 물고기의 권장 미끼를 중복 없이 모아 보여줍니다. 생미끼는 따로 구분하고, 필터를 바꾸면 목록도 함께 갱신됩니다. 기본 미끼 아무거나 가능한 어종은 특정 미끼를 필수로 안내하지 않습니다.
- 선택한 항로 위의 **항로 준비 미끼**에는 세 구역의 일반·환해류에서 현재 목적·필터에 맞는 물고기의 미끼를 모읍니다. 권장 미끼, 관측 자료가 있는 대체 미끼, 현장에서 낚을 생미끼를 구분하고 중복은 제거합니다. 직감·연쇄 생미끼 조건과 환해류 유도 물고기도 포함합니다. 도감 채우기는 수집·해제·가져오기, 선상과제는 복수 물고기군, 항로 변경과 구역별 필터에 따라 즉시 갱신됩니다. 고득점은 전체 점수 목록의 미끼를 유지하며 GP 추천 대상의 권장 미끼를 강조합니다. 대체 미끼 하나로 항로 전체를 낚을 수 있다는 뜻은 아닙니다. 미끼에 마우스를 올리면 해당 구역과 일반·환해류 구분을 확인할 수 있습니다.
- 고득점은 모든 물고기의 기본·이중·삼중 점수를 보여줍니다. 현재 GP, 사용 가능 기술, GP 효율/한 번 점수 기준으로 가능한 기술을 추천합니다. 이중 400GP·삼중 700GP, 수량 범위의 낮은 값으로 비교하며 일반 한 마리를 제외한 추가 점수로 GP 효율을 계산합니다. 자료가 없는 기술은 추천하지 않습니다.
- 추천은 목표 물고기를 낚는 데 성공한다는 전제입니다. 입질 확률, 직감·생미끼 준비 비용, 월척·보너스, GP 회복, 남은 시간과 구간 간 GP 배분은 계산하지 않습니다. 게임의 실제 날씨·직감 활성 여부를 읽지 않습니다.
- 도감은 근해 140종·원양 119종을 해역별로 표시합니다. 이름·초성 검색, 미획득 필터, 검색 결과 해역 자동 펼침, 체크 후 실행 취소를 지원합니다. 장소별 행이 중복되는 어종이 있어 행 수와 고유 종수는 다를 수 있습니다.
- 도감·항로에서 원형 체크와 `미수집 / 수집` 버튼으로 기록합니다. 도감의 수집한 행은 연한 청록색으로 표시하며, 키보드로도 연속 체크·해제할 수 있습니다.
- `기록 관리`는 별도 대화상자에 모았습니다. 원본 Export JSON, 로컬 ZIP 기록, Teamcraft 숫자 ID 배열을 가져올 수 있습니다. 유효한 잡음 기록만 기존 값에 합치며, 잘못된 입력은 저장값을 바꾸지 않습니다.
- JSON 전체 백업과 Teamcraft용 기록 복사를 지원합니다. Teamcraft로 내보낼 때는 그쪽의 `CarbunclePlushy에서 가져오기`를 이용합니다. 잡은 기록만 추가하며 여기서 해제한 체크가 Teamcraft 기록을 삭제하지 않습니다.

## 개발

별도 빌드 없이 HTTP 정적 서버 또는 GitHub Pages에서 실행합니다. 로컬 ZIP 원본은 별도 폴더에서 유지하며 이 배포본으로 덮어쓰지 않습니다.

- `scripts/entry.js`: 이전 입장 링크·캐시 화면 호환용. 인증·저장소 접근 없이 허용된 경로만 연결합니다. 새 항로·도감 페이지에서는 로드하지 않습니다.
- `css/app.css`, `scripts/app.js`: 자체 화면, 항로·도감·검색·필터·기록 관리
- `scripts/voyages.js`: KST 출항 일정, 반복 항로, 구간별 시간대·어종 판정
- `scripts/collection.js`: 수집 상태·의존 관계·GP 추천
- `scripts/achievements.js`, `data/achievements.json`: 업적 조건·추천 항로·구간별 운영 및 출처. 기존 어종 자료를 연결하는 자체 로직이며 원본 사이트 실행 코드와 공략 도표는 포함하지 않습니다.
- `scripts/teamcraft-ids.js`: 데이터에서 추출한 Teamcraft ID 대응표
- `tools/build-data.cjs`: 원본 CSV의 사실 값을 실행 불가능한 JSON으로 정규화. 수량 미확인 값은 추정하지 않으며 직감·생미끼 조건을 구조화합니다.
- `tools/build-pages.cjs`: 자체 HTML 페이지와 출처 안내 생성
- `data/fish.json`: 근해 140행·원양 120행, 총 259종. 같은 어종의 서로 다른 장소 기록을 보존합니다.

브라우저에는 자체 스크립트·공통 메뉴/입력 도우미·스타일시트를 로드합니다. 실행 시 CDN·외부 API·원본 사이트를 호출하지 않습니다. 물고기·업적 JSON과 게임 이미지, 공통 글꼴은 같은 사이트에서 읽습니다. 실시간 날씨는 조회하지 않습니다.

이 폴더에서 개발 자료 생성 및 검증:

```sh
npm ci --ignore-scripts
npm run build
npm test
```

Node.js 22 이상을 사용합니다. `jsdom`은 DOM 통합 테스트용 개발 의존성으로, 실제 페이지에서는 사용하지 않습니다. 테스트는 저장 키·원본/ZIP/Teamcraft 가져오기·내보내기·실행 취소·공개 입장과 이전 링크·조건 물고기·GP 경계·전체 항로 주기와 자료 정규화를 검증합니다.
