# LINE Seed KR

기본 글꼴로 쓰는 Regular(400)와 Bold(700)의 원본 WOFF2 파일입니다. 나눔스퀘어라운드는 보조 글꼴로 유지합니다.

- 배포처: [LINE Seed 공식 사이트](https://seed.line.me/index_kr.html)
- 원본: [LINE Seed Sans KR ZIP](https://seed.line.me/src/images/fonts/LINE_Seed_Sans_KR.zip)
- ZIP 내부 버전: `LINE_SeedKR_2023.09.06/Web/woff2/`
- 확인일: 2026-09-09
- 수정·변환 없이 포함: `LINESeedKR-Rg.woff2`, `LINESeedKR-Bd.woff2`
- 라이선스: [SIL Open Font License 1.1](./OFL.txt)

OFL.txt는 원본 글꼴에 기록된 저작권 고지와 [LINE 공식 저장소의 라이선스](https://github.com/line/seed/blob/main/OFL.txt)를 포함합니다. 개인·상업용 웹사이트에 사용할 수 있으며, 글꼴 자체를 단독 판매할 수 없습니다.
