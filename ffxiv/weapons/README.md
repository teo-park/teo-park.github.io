# 무기 수첩

[무기 수첩 열기](https://teo-park.github.io/ffxiv/weapons/)

전투 무기의 제작·획득 이력을 기록하는 무료·비영리 팬 도구입니다. 한국 패치 7.56 기준 **15개 시리즈, 260개 기록 항목, 단계별 아이템 920개**를 포함합니다. 나이트의 검과 방패를 각각 한 항목으로 셉니다.

## 포함 범위

성장형은 마지막으로 완료한 단계를 선택합니다. 중간 단계는 해당 진행 경로를 함께 표시하며, 과거 아이템을 실제로 모두 소지한다는 뜻은 아닙니다. 교환으로 이전 단계를 건너뛰었어도 현재 완료한 단계로 기록할 수 있습니다. 나이트의 검과 방패는 같은 칸에서 함께 단계를 변경합니다.

에우레카는 복원된 IL335 무기부터 맞춤형까지 포함하며, 복원 전의 잡 기본 무기는 세지 않습니다. 제작·채집 도구, 모조품의 별도 소지 여부, 일반 토벌전·제작·딥 던전·영웅 레이드 무기 전체 목록은 이번 범위에 포함하지 않습니다. 재보강 마법 신사 우산은 신곡 무기와 별개이며 IL530입니다.

무기명·시리즈명·직업명·초성을 검색하고, 직업·진행 상태·관심 표시로 필터링할 수 있습니다. 모든 분류는 직업별 한 행, 무기 시리즈별 한 열의 표로 표시합니다. 전체보기에서는 성장형 6종·절 7종·재보강 2종의 260개 기록을 한 표로 모으며, 청마도사의 마법 신사 우산도 포함합니다. 성장형 칸은 완료 단계를 선택하고, 절 무기 칸은 「수집」 버튼으로 체크합니다. 재보강 신곡은 버튼을 누를 때마다 없음 → 보강 → 재보강 → 없음으로 순환합니다. 마법 신사 우산은 실제 단계명에 맞게 없음 → 일반 → 재보강 → 없음으로 순환합니다. 나이트 검·방패는 한 개의 단계·수집·관심 버튼을 공유하고, 아이콘 두 개를 나란히 표시합니다. 각 아이콘은 해당 아이템의 상세정보를 엽니다. 상세정보에서 단계를 바꿔도 함께 적용되며 메모는 각각 보존합니다.

무기 열은 140px, 직업 열은 104px로 좁게 표시합니다. 전체보기는 가로 스크롤하며 직업명과 시리즈 제목을 고정합니다. 분류가 바뀌는 열에는 구분선을 표시합니다. 단계·수집 변경 후 표의 스크롤 위치와 선택 칸을 유지하며 기존 저장·백업·실행 취소를 그대로 사용합니다. 지원하지 않는 조합은 대시, 필터에 맞지 않는 칸은 「조건 제외」입니다. 직업별 완성 개수는 검색·상태·관심 필터에 관계없이 현재 분류·시리즈 범위 전체 기준입니다. 처음에는 성장형 진행표를 보여주며 마지막 필터 설정을 기억합니다.

## 전체 현황 이미지

상단 **전체 현황 · 이미지**에서 직업 한 행, 무기 시리즈 한 열로 전체 기록을 모아 봅니다. 나이트 검·방패는 같은 칸 안에서 왼쪽·오른쪽으로 구분합니다. 완성·수집은 금색 체크, 성장 중은 완료 단계/전체 단계, 미수집은 흐린 아이콘과 원으로 표시합니다. 지원하지 않는 직업·시리즈 조합은 대시입니다.

이름, 밤하늘/양피지 배경, 전체/성장형/절/재보강 범위를 선택하고 **이미지 복사** 또는 **PNG 저장**을 누릅니다. 이미지 복사를 허용하지 않는 브라우저에서는 PNG 파일을 사용할 수 있습니다. 실제 PNG를 미리 보여주므로 복사한 이미지도 동일합니다. 작은 화면에서는 크게 보기와 스크롤로 확인하고 텍스트 현황도 열 수 있습니다.

검색·목록 필터·페이지 번호는 공유 범위에 영향을 주지 않습니다. 기록한 직업만 숨김/표시해도 달성률 분모는 해당 범위 전체 무기 수를 유지합니다. 메모와 관심 표시는 이미지에 넣지 않습니다. 이미지 준비와 복사는 브라우저 안에서 처리하며, 수집 기록을 서버에 보내지 않습니다.

아이콘 526개는 XIVAPI에서 받은 원본 PNG를 `data/weapon-icons.json`에 묶어 제공합니다. 브라우저가 수백 번의 외부 이미지 요청을 보내지 않도록 하며, 공통 글꼴을 준비한 뒤 두 배 해상도로 그립니다. 아이콘을 읽을 수 없으면 수집 상태를 유지한 대체 기호와 재시도 안내를 표시합니다. 데이터 갱신 후 `npm run cache-icons`로 아이콘 묶음도 갱신하세요.

## 저장과 백업

- 수집 기록: `teo-ffxiv.weapons.collection.v1`, 필터와 보기: `teo-ffxiv.weapons.preferences.v1`.
- 서버로 기록을 전송하지 않습니다. 게임 계정이나 소지품을 자동으로 읽지 않습니다.
- **수집 기록 관리**에서 JSON 파일을 내보내거나 파일·붙여넣기로 복원합니다. 미리보기 후 적용합니다.
- 기본 합치기는 더 높은 단계와 관심 표시를 보존합니다. 새 메모가 있으면 가져온 메모를 사용합니다. **교체**는 백업에 없는 기록까지 지우므로 미리보기에서 구분합니다.
- 단계는 아이템 ID로 기록합니다. 나이트 검·방패, 다른 직업에 해당하는 아이템을 잘못 가져오면 전체 가져오기를 거부합니다. 다른 버전의 알 수 없는 기록 항목은 보존합니다.
- 기존 백업과 아이템별 집계는 유지합니다. 검·방패의 단계가 다른 기록은 자동으로 변경하지 않고 「단계 다름」 또는 일부 수집 상태로 표시합니다. 다음 단계 선택은 두 아이템에 한 번에 적용됩니다. 순환 버튼은 서로 다를 때 우선 높은 단계로 맞춘 뒤 정상 순환하며, 실행 취소로 기존의 서로 다른 단계와 메모까지 복구할 수 있습니다.
- 손상된 저장 데이터는 자동으로 덮어쓰지 않습니다. 원본을 내려받은 뒤 정상 백업으로 명시적으로 교체할 수 있습니다. 저장 실패 시 성공으로 표시하지 않습니다.
- 다른 기기에서는 백업 파일을 가져와야 합니다. 브라우저 데이터 삭제에 대비해 백업하세요.

## 개발

정적 HTML/CSS/ES module 페이지이며 별도 빌드 없이 GitHub Pages에서 작동합니다.

```sh
cd ffxiv/weapons
npm ci --ignore-scripts
npm test
npm run update-data
```

데이터 생성기는 고정 리비전의 CSV와 명시적인 아이템 ID 목록을 사용합니다. 중복 ID, 누락된 한국어 이름, 장비 직업·슬롯 불일치, 단계 누락 시 생성을 중단합니다. 새 시리즈나 단계 추가 시 생성 스크립트와 범위 테스트를 함께 업데이트하세요.
