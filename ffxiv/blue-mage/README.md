# 청마도사 스킬 수첩

[수첩 열기](https://teo-park.github.io/ffxiv/blue-mage/)

청마법 124종의 습득 여부를 기록하는 무료·비영리 팬 도구입니다. 로그인 없이 이 브라우저에 저장합니다.

- 번호순: 한 페이지 30종, 데스크톱 5열·6행. 아이콘으로 습득 체크하고 별도 버튼으로 습득처를 확인합니다.
- 장소별: 같은 필드·임무·가면 무투회에서 배울 청마법을 함께 표시합니다. 한 청마법에 여러 경로가 있으면 각 장소에 표시합니다.
- 검색: 수첩 번호, 한글·영문 이름, 초성, 마물과 장소. 미습득·습득, 습득 방법, 장소, 속성, 등급을 함께 좁힐 수 있습니다.
- 수집 기록 관리: `1-10, 13, 24`처럼 번호로 한 번에 추가하거나 JSON으로 백업·복원합니다. 가져오기는 기존 기록에 추가하며, 다른 수첩의 파일은 받지 않습니다.
- 체크한 타일은 즉시 사라지지 않습니다. 미습득 필터에서는 ‘체크 반영해 목록 정리’를 눌러 정리합니다. 최근 변경은 실행 취소할 수 있습니다.

저장 키는 `teo-ffxiv.blue-mage.collection.v1`입니다. 브라우저 데이터를 지우기 전이나 다른 기기로 옮길 때 백업해 주세요. 기록은 서버로 전송하지 않습니다. 아이콘은 외부 이미지 주소에서 불러옵니다.

## 데이터 범위와 출처

2026-09-08에 수집한 공개 목록 기준 **124종·169개 습득 경로·107개 장소**를 포함합니다. 목록은 패치 6.45까지 추가된 청마법이며, 데이터 기준일과 게임 패치는 서로 다릅니다.

- 목록·아이콘 URL·습득처 원문: [FFXIV Collect 공개 API](https://ffxivcollect.com/api/spells), [청마법 목록](https://ffxivcollect.com/spells). [Collect MIT 라이선스](../triple-triad/licenses/ffxiv-collect-MIT.txt).
- 한국어 스킬·마물·장소 명칭, 청마도서 번호·등급·공격 유형·속성·시전 시간 등: [한국어 게임 데이터](https://github.com/Ra-Workspace/ffxiv-datamining-ko/tree/9431b6ce34e0f5b79686f71b585769819f81ae2b). 영어 원문과 연결할 때 [XIVAPI 게임 데이터](https://github.com/xivapi/ffxiv-datamining/tree/64ff8a5d2903b429cb9d95066547ce57fc53bfc8)의 동일 행 번호를 사용합니다.
- 체득 방법·청마법 우상 안내: [한국 공식 청마도사 가이드](https://guide.ff14.co.kr/job/BlueMage/18?type=E). 우상 안내는 잡 퀘스트 ‘청가면 탄생’ 완료 후 울다하 달 회랑의 괴짜 가히쟈(X:12.5 Y:12.9)를 기준으로 표시합니다.
- 임무별 공식 링크: [한국 공식 임무 데이터베이스](https://guide.ff14.co.kr/lodestone/db/duty). 기존 임무 초성 사전 데이터와 이름을 연결합니다. 필드는 공식 가이드 검색으로 연결합니다.

Collect 내부 ID와 게임 수첩 번호는 다릅니다. 예를 들어 물대포는 수첩 No.001, Collect ID 3입니다. 저장과 번호 검색에는 수첩 번호를 사용하며 외부 링크에는 원본 ID를 사용합니다.

습득처는 공개 자료의 스냅샷입니다. 원문에 없는 드롭률·확률·추정 좌표나 모든 대체 마물을 추가하지 않았습니다. 게임 업데이트로 마물·습득처가 달라질 수 있어 상세 화면에 원문과 개별 출처 링크를 함께 표시합니다. 긴 스킬 설명·세계관 문장은 복제하지 않으며, 수치는 기본값으로 실제 전투 중 보정은 반영하지 않습니다.

물의 숨결의 리바이어선 경로와 관통산탄의 라바나 경로는 원문에 토벌전 난이도가 없습니다. 전투 지역명으로 표시하고 ‘토벌전’으로 분류하며, 특정 난이도로 단정하지 않습니다.

우상의 ‘습득 개수 조건 충족’은 이 수첩에서 체크한 개수만 비교합니다. 실제 캐릭터의 레벨·퀘스트·가면 무투회 완료 여부는 자동 확인하지 않습니다.

## 갱신과 검증

저장소 루트에서 실행:

```sh
node ffxiv/blue-mage/scripts/update-data.mjs --refresh
cd ffxiv/blue-mage
npm ci --ignore-scripts
npm test
```

갱신 스크립트는 공개 데이터만 읽고, 저장소의 `.cache/blue-mage/`에 원본과 데이터 리비전을 보관합니다. `--refresh`를 생략하면 캐시를 재사용합니다. 사용자의 습득 기록은 접근하지 않습니다. CSV 파서는 카드 수첩의 갱신 스크립트를 공용으로 사용합니다. 미번역 이름·미분류 습득처·수첩 번호 불일치가 있으면 생성을 중단합니다.

정적 페이지이므로 배포 시 빌드·패키지 설치는 필요 없습니다. `npm` 의존성은 DOM 검증용입니다.
