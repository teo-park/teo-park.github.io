# 청마도사 스킬 수첩

[수첩 열기](https://teo-park.github.io/ffxiv/blue-mage/)

청마법 124종의 습득 여부를 기록하는 무료·비영리 팬 도구입니다. 로그인 없이 이 브라우저에 저장합니다.

- 번호순: 한 페이지 30종, 데스크톱 5열·6행. 아이콘으로 습득 체크하고 별도 버튼으로 습득처를 확인합니다.
- 장소별: 같은 필드·임무·가면 무투회에서 배울 청마법을 함께 표시합니다. 한 청마법에 여러 경로가 있으면 각 장소에 표시합니다.
- 검색: 수첩 번호, 한글·영문 이름, 초성, 마물과 장소. 미습득·습득, 습득 방법, 장소, 속성, 등급을 함께 좁힐 수 있습니다.
- 수집 기록 관리: `1-10, 13, 24`처럼 번호로 한 번에 추가하거나 JSON으로 백업·복원합니다. 가져오기는 기존 기록에 추가하며, 다른 수첩의 파일은 받지 않습니다.
- 캡처로 등록: 청마도서의 4열 × 4행 화면을 파일 선택 또는 Ctrl+V로 추가합니다. 회색 `?` 아이콘은 미습득으로 읽고, 아이콘 왼쪽의 작은 활성화 체크박스는 판정에서 제외합니다. 이미지 위의 습득·미습득 표시를 눌러 수정할 수 있습니다.
- 체크한 타일은 즉시 사라지지 않습니다. 미습득 필터에서는 ‘체크 반영해 목록 정리’를 눌러 정리합니다. 최근 변경은 실행 취소할 수 있습니다.

저장 키는 `teo-ffxiv.blue-mage.collection.v1`입니다. 브라우저 데이터를 지우기 전이나 다른 기기로 옮길 때 백업해 주세요. 기록은 서버로 전송하지 않습니다. 아이콘은 외부 이미지 주소에서 불러옵니다.

상단의 1–8 페이지 번호 줄과 금색 선택 테두리가 보이면 게임 페이지도 자동으로 선택합니다. 번호 줄이 잘렸거나 흐리거나 선택 표시가 여러 곳에 있으면 추측하지 않고 직접 선택을 요청합니다. 자동 선택은 언제든 수정할 수 있으며, 직접 고른 번호는 캡처를 다시 열거나 다시 인식해도 유지합니다. 번호순·필터 해제 상태를 기준으로 한 페이지 16종을 연결합니다. 8페이지는 No.113–124의 12칸만 읽습니다. 영역이 맞지 않으면 ‘아이콘 영역 조정’에서 4×4 칸 영역을 드래그한 뒤 다시 인식하세요. 자동으로 페이지를 찾았더라도 번호와 습득 상태를 확인한 캡처만 등록할 수 있습니다.

캡처 등록은 **습득한 번호만 추가**합니다. `?`로 읽힌 번호도 기존 기록에서 해제하지 않으며, 실행 취소로 방금 등록만 되돌릴 수 있습니다. 여러 장은 각 페이지를 한 번씩 선택하고 확인합니다. PNG·JPG·WebP·BMP를 최대 12장, 파일당 12MB까지 받을 수 있습니다. 캡처는 서버에 업로드하거나 백업 파일에 포함하지 않습니다. 브라우저에는 일반적인 물음표의 작은 명도 비교 패턴만 포함하며, 원본 샘플 캡처는 배포하지 않습니다. 크기·압축·다른 UI 테마에 따라 오인식할 수 있어 검토 화면을 거칩니다.

## 데이터 범위와 출처

2026-09-08에 수집한 공개 목록 기준 **124종·169개 습득 경로·107개 장소**를 포함합니다. 목록은 패치 6.45까지 추가된 청마법이며, 데이터 기준일과 게임 패치는 서로 다릅니다.

- 목록·아이콘 URL·습득처 원문: [FFXIV Collect 공개 API](https://ffxivcollect.com/api/spells), [청마법 목록](https://ffxivcollect.com/spells). [Collect MIT 라이선스](../triple-triad/licenses/ffxiv-collect-MIT.txt).
- 한국어 스킬·마물·장소 명칭, 청마도서 번호·등급·공격 유형·속성·시전 시간 등: [한국어 게임 데이터](https://github.com/Ra-Workspace/ffxiv-datamining-ko/tree/9431b6ce34e0f5b79686f71b585769819f81ae2b). 영어 원문과 연결할 때 [XIVAPI 게임 데이터](https://github.com/xivapi/ffxiv-datamining/tree/64ff8a5d2903b429cb9d95066547ce57fc53bfc8)의 동일 행 번호를 사용합니다.
- 체득 방법·청마법 우상 안내: [한국 공식 청마도사 가이드](https://guide.ff14.co.kr/job/BlueMage/18?type=E). 우상 안내는 잡 퀘스트 ‘청가면 탄생’ 완료 후 울다하 달 회랑의 괴짜 가히쟈(X:12.5 Y:12.9)를 기준으로 표시합니다.
- 임무별 공식 링크: [한국 공식 임무 데이터베이스](https://guide.ff14.co.kr/lodestone/db/duty). 기존 임무 초성 사전 데이터와 이름을 연결합니다. 필드는 공식 가이드 검색으로 연결합니다.

Collect 내부 ID와 게임 수첩 번호는 다릅니다. 예를 들어 물대포는 수첩 No.001, Collect ID 3입니다. 저장과 번호 검색에는 수첩 번호를 사용하며 외부 링크에는 원본 ID를 사용합니다.

습득처는 공개 자료의 스냅샷입니다. 원문에 없는 드롭률·확률·추정 좌표나 모든 대체 마물을 추가하지 않았습니다. 게임 업데이트로 마물·습득처가 달라질 수 있어 상세 화면에 원문과 개별 출처 링크를 함께 표시합니다. 긴 스킬 설명·세계관 문장은 복제하지 않으며, 수치는 기본값으로 실제 전투 중 보정은 반영하지 않습니다.

물의 숨결의 리바이어선 경로와 관통산탄의 라바나 경로는 원문에 토벌전 난이도가 없습니다. 전투 지역명으로 표시하고 ‘토벌전’으로 분류하며, 특정 난이도로 단정하지 않습니다.

우상의 ‘습득 개수 조건 충족’은 이 수첩에서 체크한 개수만 비교합니다. 실제 캐릭터의 레벨·퀘스트·가면 무투회 완료 여부는 자동 확인하지 않습니다.

## 스킬 조합과 사용 순서

‘조합·사용 순서 추천’에서 탱·힐·딜 역할과 토벌전·레이드 보스 / 파티 던전 / 혼자 던전을 선택합니다. **현재 수첩에서 습득 체크한 기술만 최대 24개** 추천합니다. 전부 채우는 것보다 역할에 맞는 기술을 우선하며, 빈 칸은 남겨 둡니다. Lv.80과 현재 수첩의 124종을 대상으로 하는 기본안이며, 개별 보스 공략이나 최적 피해량 계산기는 아닙니다. 혼자 던전은 탱커 복사 기준입니다.

추천 엔진은 역할 핵심 → 임무에 필요한 기술 → 직접 선택한 차단·해제·교대·파티 담당 → 기본 공격과 연계·추가 공격 순서로 구성합니다. 같은 재사용 시간을 공유하는 기술은 한 개만 고르고, 물리 강화 버프는 함께 쓸 공격이 있을 때만 넣습니다. 초진동은 빙결의 포효와 함께 추천하며, 둘을 갖추지 못하면 배운 레벨 5 데스를 대안으로 선택할 수 있습니다. 즉사 면역 여부와 성공 가능성은 별도로 확인해야 합니다. 미습득 핵심·담당 기술은 임시 조합 경고와 습득처로 연결하며, 장착 수에 포함하지 않습니다.

수집 체크·캡처 등록·번호 입력·백업 가져오기·실행 취소·다른 탭의 변경이 추천에 반영됩니다. 추천 옵션과 조합 복사는 습득 기록을 바꾸지 않습니다. 이 페이지는 게임의 활성 기술을 변경하지 않습니다.

사용 순서는 기본 우선순위, 상황별 연계, 달의 피리 시작 순서로 나눕니다. 호루라기·찌릿찌릿과 삼단 작살, 노발대발과 강화 대상, 관통산탄 4회 연속, 회복·보호막, 적 모으기·빙결·초진동을 다룹니다. 흐름에는 실제 추천 조합에 들어간 기술만 표시합니다. 신속한 마법은 역할 기술이므로 청마법 24칸에 포함하지 않습니다.

딜러의 기본 2분 시작 순서는 필요한 청마법을 모두 장착한 보스 기본안에서만 표시합니다. 일부 기술이 없거나 다른 지속 피해를 담당하면 짧은 연계 예시로 전환하며, 원본 순서에서 누락 기술만 삭제해 완성 오프너처럼 표시하지 않습니다. 짧은 예시는 사용 순서를 익히기 위한 것으로 최적 몰아치기를 보장하지 않습니다. 장비·시전 속도·지연·충전 상태·보스 기믹은 계산하지 않습니다. 달의 피리 이후의 15초 행동 불가와 귀수각 마무리 방식 차이를 안내합니다. 탱·힐 기본안은 회복·생존을 우선해 달의 피리를 넣지 않습니다.

2026-09-08 확인한 다음 자료의 게임 동작과 역할별 운영 원칙을 참고해 자체 우선순위·한국어 설명·UI를 작성했습니다. 가이드 사이트의 코드나 이미지 레이아웃을 복제하지 않습니다. 한국 수첩에 없는 기술이나 글로벌 가이드의 패치 표기를 한국 패치로 간주하지 않습니다.

- [한국 공식 청마도사 가이드](https://guide.ff14.co.kr/job/BlueMage/18?type=E): 청마법 활성화 한도와 역할 기술.
- [FFXIV Collect 기술 API](https://ffxivcollect.com/api/spells): 연계 조건·공유 재사용 시간. 긴 설명·세계관 문장은 배포하지 않습니다.
- Blue Academy의 [탱커](https://mage.blue/gameplay/tank/), [힐러](https://mage.blue/gameplay/healer/), [딜러](https://mage.blue/gameplay/dps/), [혼자 던전](https://mage.blue/gameplay/solo/): 역할별 기술 선택과 운영 원칙.
- Blue Academy의 [Moon Flute Opener](https://mage.blue/gameplay/moon-flute-opener/): Winged Reprobation 시작 순서의 마법·능력 배치, 신속한 마법·관통산탄·귀수각 순서. 연계 예시는 이 자료와 기술 동작을 바탕으로 구성한 자체 간략안입니다.

`loadouts.js`의 순수 함수와 DOM 테스트에서 24칸 한도, 습득 기술 제한, 공유 재사용 시간, 버프·공격 연계, 미습득 핵심, 불완전한 오프너, 기록 변경 반영과 복사를 검증합니다.

## 갱신과 검증

저장소 루트에서 실행:

```sh
node ffxiv/blue-mage/scripts/update-data.mjs --refresh
cd ffxiv/blue-mage
npm ci --ignore-scripts
npm test
```

갱신 스크립트는 공개 데이터만 읽고, 저장소의 `.cache/blue-mage/`에 원본과 데이터 리비전을 보관합니다. `--refresh`를 생략하면 캐시를 재사용합니다. 사용자의 습득 기록은 접근하지 않습니다. CSV 파서는 카드 수첩의 갱신 스크립트를 공용으로 사용합니다. 미번역 이름·미분류 습득처·수첩 번호 불일치가 있으면 생성을 중단합니다.

정적 페이지이므로 배포 시 빌드·패키지 설치는 필요 없습니다. `npm` 의존성은 DOM 검증용입니다.
