# 임무 초성 사전

[서비스](https://teo-park.github.io/ffxiv/duty-finder/) · [한국 공식 가이드 임무 DB](https://guide.ff14.co.kr/lodestone/db/duty)

초성·이름 일부·한글과 초성의 혼합 입력으로 임무의 정식 이름을 찾습니다. 예: `ㅅㅅㅌㅅ`, `ㅇㅍㄹㅌ`, `극ㅇㅍㄹㅌ`. 띄어 쓴 검색어는 모두 포함하는 결과를 찾으며, 콘텐츠 종류를 함께 선택할 수 있습니다. 조합 중인 마지막 글자도 검색에 반영합니다.

처음에는 임무 이름을 펼치지 않습니다. 검색 결과에는 정식 이름·초성·레벨·공식 분류·확장팩·평균 아이템 레벨(공식 가이드에 있을 때)과 공식 링크를 표시합니다. 공략, 줄거리, 보스 설명, 이미지는 수집하지 않습니다. 커뮤니티 별명이나 공식 이름에 없는 축약어 사전은 포함하지 않습니다.

2026-09-06 확인: 총 400개. 던전 103, 길드 작전 14, 토벌전 104, 레이드 155, PvP 16, 절 레이드 7, 멸 연합 레이드 1. 분류는 공식 가이드를 따릅니다. 브라우저에서 정적 스냅샷을 검색하며 외부 API나 저장소로 검색어를 보내지 않습니다.

## 데이터 갱신

저장소 루트에서 Node.js 20 이상으로 실행합니다.

```sh
node duty-finder/scripts/update-data.mjs
node --test duty-finder/tests/duty-finder.test.cjs
```

갱신 스크립트는 공식 분류별 페이지를 마지막 페이지까지 수집하고, 중복 ID·잘못된 분류·빈 페이지·불완전한 목록을 검사한 뒤에만 `data.js`를 씁니다. 변경된 데이터와 개수를 검토하고 HTML의 데이터 버전 및 이 문서의 확인일·개수를 갱신한 후 배포합니다.
