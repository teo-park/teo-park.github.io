# 부대 수집방

비밀번호로 참여한 사람끼리 청마법·무기·극 탈것·어부·카드·꼬마친구·마수도감 현황을 공유합니다. Google 로그인 후 **기존 기록 불러오고 연결**을 누르면 이 브라우저의 체크를 불러오고, 이후 수첩과 수집방 양쪽의 체크·해제를 동기화합니다.

방 비밀번호는 숫자·문자를 포함해 4~128자로 설정할 수 있습니다.

방마다 공유할 수첩을 선택할 수 있습니다. ‘같이할 목표’에서 나와 미수집이 겹치는 사람을 찾거나 ‘같이하고 싶어요’를 표시하고, 모집 문구를 복사해 부대 채팅에 붙여넣으세요. 다른 참여자에게 메시지를 자동으로 보내지는 않습니다.

기존 기록을 처음 불러오는 작업은 기록이 있는 브라우저에서 해야 합니다. 다른 기기에서는 같은 Google 계정으로 로그인하고 수첩을 연결하세요. 무기 메모는 브라우저에만 보관합니다. 극 탈것은 확장팩별로 볼 수 있으며, 기존 방은 공유 설정에서 새 수첩을 선택해야 합니다.

구현·배포·권한·동기화 정책과 테스트는 [서비스 안내](../../services/collection-rooms/README.md)에 있습니다. 공개 데이터의 출처·권리는 각 원래 수첩의 안내를 따릅니다. 방에서는 이미 배포 중인 공개 게임 메타데이터의 이름·획득처 요약만 사용합니다.
